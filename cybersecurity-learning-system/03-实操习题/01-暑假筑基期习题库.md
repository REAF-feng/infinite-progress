#### B-2 文本处理实战

**任务描述**：
使用 exercises/logs/access.log，完成以下分析：

```
1. 找出所有包含 "404" 的行
2. 找出所有不包含 "200" 的行（注意：200可能出现在IP地址中）
3. 统计有多少个不同的IP地址
4. 统计每个IP地址各出现了多少次，按出现次数从多到少排列
5. 统计GET请求和POST请求各有多少次
```

**标准解答**：
```bash
cd ~/exercises/logs/

# 1. 找出404行
grep " 404 " access.log
# 注意用" 404 "而不是"404"，避免匹配IP中的404

# 2. 不包含200的行（注意空格避免误匹配）
grep -v " 200 " access.log

# 3. 统计不同IP数
awk '{print $1}' access.log | sort -u | wc -l

# 4. 每个IP出现次数排序
awk '{print $1}' access.log | sort | uniq -c | sort -rn

# 5. GET和POST各多少次
echo "GET count: $(grep -c 'GET' access.log)"
echo "POST count: $(grep -c 'POST' access.log)"
```

**排错思路**：
- `sort | uniq -c` 结果不对？→ 先检查sort是否正确（可能没排序）
- `grep "200"` 匹配到了IP地址中的200？→ 用空格包围关键词 `grep " 200 "`
- awk `{print $1}` 输出不对？→ 检查access.log是否用空格分隔

### C档：综合拓展题

#### C-1 搭建个人学习日志系统

**任务描述**：
创建一个Shell脚本 `~/exercises/learning-log.sh`，运行后自动生成学习日志。

```
要求：
1. 脚本运行时显示菜单：
   === Learning Log System ===
   1) Add new log entry
   2) View today's log
   3) Search logs
   4) Exit

2. 选项1：提示用户输入内容，自动加上时间戳，追加到 daily-log.txt
3. 选项2：用cat显示今天的日志文件
4. 选项3：提示用户输入关键词，用grep搜索日志
5. 脚本必须有执行权限，能 ./learning-log.sh 直接运行
```

**标准解答**：
```bash
#!/bin/bash
# 学习日志系统

LOG_FILE="$HOME/exercises/daily-log.txt"

# 确保日志文件存在
touch "$LOG_FILE"

show_menu() {
    echo ""
    echo "=== Learning Log System ==="
    echo "1) Add new log entry"
    echo "2) View today's log"
    echo "3) Search logs"
    echo "4) Exit"
    echo ""
}

while true; do
    show_menu
    read -p "Choose an option (1-4): " choice
    
    case $choice in
        1)
            read -p "Enter your log entry: " entry
            echo "[$(date '+%Y-%m-%d %H:%M:%S')] $entry" >> "$LOG_FILE"
            echo "✓ Log saved!"
            ;;
        2)
            echo "=== Today's Log ==="
            cat "$LOG_FILE"
            ;;
        3)
            read -p "Enter search keyword: " keyword
            echo "=== Search Results ==="
            grep -i "$keyword" "$LOG_FILE" || echo "No results found."
            ;;
        4)
            echo "Goodbye! Keep learning!"
            exit 0
            ;;
        *)
            echo "Invalid option. Please choose 1-4."
            ;;
    esac
done
```

**常见报错解决**：
| 报错 | 原因 | 解决 |
|------|------|------|
| `Permission denied` | 没有执行权限 | `chmod +x learning-log.sh` |
| `bad interpreter` | 脚本格式问题（Windows换行符） | `sed -i 's/\r$//' learning-log.sh` |
| `read: command not found` | 用了sh而不是bash运行 | 用 `bash learning-log.sh` 或 `./learning-log.sh` |

## 第六周：安全入门（Day36-42）

### B档：DVWA搭建与基础漏洞

#### B-6 DVWA环境搭建

```bash
# DVWA (Damn Vulnerable Web Application) 是经典入门靶场

# 步骤1：安装LAMP环境
sudo apt update
sudo apt install apache2 mariadb-server php php-mysqli php-gd -y

# 步骤2：启动服务
sudo systemctl start apache2
sudo systemctl start mariadb

# 步骤3：下载DVWA
cd /var/www/html/
sudo git clone https://github.com/digininja/DVWA.git
sudo chmod -R 777 DVWA/

# 步骤4：配置DVWA
cd DVWA/config/
sudo cp config.inc.php.dist config.inc.php
sudo nano config.inc.php
# 修改数据库密码（如果是Kali默认MariaDB，密码为空）

# 步骤5：在Kali浏览器访问
# http://localhost/DVWA/setup.php
# 点击 "Create / Reset Database"

# 步骤6：登录
# 默认用户名：admin
# 默认密码：password
```

**常见问题**：
- 数据库连接失败 → `sudo systemctl start mariadb`
- PHP模块缺失 → `sudo apt install php-{mysqli,gd,json} -y`
- 文件权限问题 → `sudo chmod -R 777 /var/www/html/DVWA/`
