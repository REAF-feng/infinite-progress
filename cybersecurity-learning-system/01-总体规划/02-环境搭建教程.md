# 零基础虚拟机环境搭建教程

> **目标**：在Windows电脑上安装VMware虚拟化软件，并在虚拟机中安装Kali Linux
> **全程耗时**：约1.5-2小时（取决于网速）
> **前提**：Windows 10/11电脑，至少8GB内存，50GB以上空闲硬盘空间

---

## 第一部分：前置概念——什么是虚拟机？

### 通俗类比：虚拟机 = 电脑中的"模拟器"

想象你有一套房（你的Windows电脑），你在这套房子里划出一个房间，这个房间可以完全独立运行，有自己的门锁、自己的家具、自己的规则，和外面完全隔离，就算里面着火（中病毒），外面的房子也不受影响。

- **宿主机（Host）**：你的Windows电脑本身
- **虚拟机（VM）**：在Windows里用软件"模拟"出来的另一台电脑
- **Kali Linux**：我们要在虚拟机里安装的操作系统，是安全测试的"瑞士军刀"

### 关键术语（零基础版）

| 术语 | 大白话解释 |
|------|-----------|
| VMware Workstation | 一个软件，用来在Windows里"造"虚拟机 |
| Kali Linux | 一个操作系统，里面预装了600+安全工具 |
| ISO镜像文件 | 一个文件，相当于"操作系统安装光盘"的数字版 |
| 虚拟硬盘 | 从你的真实硬盘里"借"一块空间给虚拟机用 |
| 虚拟内存 | 从你的真实内存里"借"一部分给虚拟机用 |

## 第三部分：下载Kali Linux镜像

### Kali Linux是什么？

Kali Linux是一个专门为安全测试设计的操作系统（Linux的一种），里面预装了Nmap、Burp Suite、Metasploit等600多个安全工具，相当于安全工程师的"工具包"。

### 下载步骤

```
第1步：打开浏览器，访问 Kali Linux 官方下载页面
       https://www.kali.org/get-kali/#kali-platforms

第2步：选择 "Virtual Machines" 标签
       原因：官方提供了已安装好的虚拟机文件，下载就能用！

第3步：选择 "VMware" 版本
       你会看到一个 .7z 压缩包文件的下载链接

第4步：点击下载（文件约3-4GB，请耐心等待）
       建议用下载工具（如IDM、NDM）加速下载

备用方案：如果官网下载慢，可以搜索 "Kali Linux VMware 镜像 清华源"
         清华大学开源镜像站提供国内高速下载
```

### 下载后解压

```
下载完成后，你会得到一个类似 kali-linux-2024.1-vmware-amd64.7z 的文件

解压步骤：
第1步：安装7-Zip解压软件（免费）
       下载地址：https://www.7-zip.org/
       安装：双击安装，一路"Next"

第2步：右键点击 .7z 文件 → "7-Zip" → " Extract Here"（解压到当前文件夹）
       解压后会生成一个文件夹，里面有 .vmx 和 .vmdk 等文件
```

> 📌 .vmx 文件就是"虚拟机配置文件"——这是你打开虚拟机的入口。

## 第四部分：导入并启动Kali虚拟机

### 步骤1：在VMware中打开Kali

```
第1步：打开VMware Workstation Pro

第2步：点击左上角 "文件(F)" → "打开(O)..."（或直接按 Ctrl+O 快捷键）

第3步：找到你刚才解压出来的文件夹
       选择里面的 .vmx 文件（文件类型是"VMware虚拟机配置文件"）
       点击"打开"

第4步：你会看到Kali Linux出现在VMware左侧的虚拟机列表中
```

### 步骤2：调整虚拟机设置（重要！）

```
第1步：在VMware左侧列表，点击选中你的Kali虚拟机

第2步：点击右侧的"编辑虚拟机设置"

第3步：调整以下配置（根据你电脑实际情况）：
       
       【内存(Memory)】
       → 拖动滑块，建议设为 2048 MB（2GB）到 4096 MB（4GB）
       → 不要超过你电脑实际内存的一半！
       → 例如：你的电脑是8GB内存，就设成2GB
       → 你的电脑是16GB内存，可以设成4GB
       
       【处理器(Processor)】
       → 处理器数量：1
       → 每个处理器的核心数：2
       → （给虚拟机2个CPU核心，不影响你正常使用电脑）
       
       【网络适配器(Network Adapter)】
       → 网络连接模式：选择 "NAT 模式(N)"
       → NAT模式 = 虚拟机通过你的电脑上网，相当于你的电脑是"路由器"
       → 这是最省心的模式，选它就对了！

第4步：点击"确定"保存设置
```

### 步骤3：启动Kali Linux！

```
第1步：点击 "开启此虚拟机"（绿色三角形播放按钮）

第2步：等待启动……（1-2分钟）
       你会看到一堆英文滚动——不要慌！这是正常的启动信息。
       就像Windows开机时那个转圈圈的动画一样。

第3步：出现登录界面！
       默认用户名：kali
       默认密码：kali
       输入密码时屏幕不会显示任何字符（包括***）——这是Linux的安全设计
       输完按回车即可

第4步：登录成功！
       你现在看到的就是Kali Linux桌面——有点像Windows，但又不完全一样。
```

## 第五部分：虚拟机使用基础操作

### 5.1 鼠标切换

```
问题：鼠标点进虚拟机后，发现鼠标"出不来"了？

解决：按 Ctrl + Alt 组合键，鼠标就会从虚拟机里释放回来。

进阶设置（让鼠标丝滑切换）：
1. 在虚拟机菜单栏点击 "虚拟机(M)" → "安装 VMware Tools..."
2. 按提示安装完成后，鼠标就可以在宿主机和虚拟机之间自由滑动了
```

### 5.2 打开终端（命令行）

```
终端 = Windows里的"命令提示符"（黑窗口）= 这是你未来最常打交道的东西

打开方法：
方法一：点击桌面左上角的终端图标（黑色方框图标）
方法二：右键桌面空白处 → "Open Terminal Here"（在这里打开终端）
方法三：快捷键 Ctrl + Alt + T

打开后你应该看到一个黑窗口，上面写着：
kali@kali:~$ _
（这个光标在闪，等着你输入命令）
```

### 5.3 第一条命令——验证环境正常

```bash
# 输入以下命令（注意：Linux命令区分大小写！）：

whoami
# 作用：显示当前登录的用户名
# 输出：kali
# 解释：告诉你"你现在是谁"

pwd
# 作用：显示当前所在的目录路径
# 输出：/home/kali
# 解释：告诉你"你现在在哪个文件夹"

uname -a
# 作用：显示系统版本信息
# 输出：Linux kali 6.x.x-... x86_64 GNU/Linux
# 解释：告诉你系统是什么版本

# 三条命令都正常输出 → 环境OK！
```

### 5.4 如何关机

```
方法一（推荐）：在终端输入命令
    sudo shutdown -h now
    解释：sudo=管理员权限，shutdown=关机，-h=halt停止，now=立刻

方法二：点击桌面右上角的电源图标 → "Power Off..."

方法三：在VMware菜单点击 "虚拟机(M)" → "电源(P)" → "关闭客户机(G)"

⚠️ 千万不要直接点VMware窗口右上角的X关闭！相当于拔电源，可能损坏系统！
```

## 第七部分：常见问题与解决

| 问题 | 原因 | 解决方法 |
|------|------|----------|
| VMware提示"Hyper-V冲突" | Windows开启了虚拟化平台 | 以管理员打开PowerShell，输入 `bcdedit /set hypervisorlaunchtype off`，重启电脑 |
| 虚拟机启动黑屏 | 显卡加速冲突 | 虚拟机设置→显示器→取消"加速3D图形"勾选 |
| Kali登录密码错误 | 新版本Kali默认密码已不再为kali | 用户名kali，密码kali；如仍错误，搜索"Kali最新版本默认密码" |
| 虚拟机无法联网 | NAT服务未启动 | Windows搜索"服务"→找到"VMware NAT Service"→右键启动 |
| "VMware Tools"安装失败 | 权限问题 | 在终端执行 `sudo apt update && sudo apt install open-vm-tools-desktop -y` |
