# 英文安全术语对照表

> 专为英语高考135分的安全学习者打造——利用你的英语优势直接阅读英文一手资料。
> 按学习阶段分组，每个术语附带在安全语境中的实际用法。

## 第一阶段：计算机与网络基础

| 英文术语 | 中文翻译 | 安全语境中的含义 |
|----------|----------|-----------------|
| **Operating System (OS)** | 操作系统 | Kali Linux is a Debian-based OS designed for penetration testing. |
| **Kernel** | 内核 | The kernel is the core of the OS — it manages hardware and system resources. |
| **Shell** | 命令行解释器 | The shell is the interface between you and the kernel. Bash is the most common shell. |
| **File System** | 文件系统 | Linux uses a hierarchical file system — everything starts from `/` (root). |
| **Permission** | 权限 | File permissions (rwx) control who can read, write, or execute a file. |
| **Root** | 根/超级管理员 | "Root" means two things: the root of the filesystem (`/`) and the superuser account. |
| **Process** | 进程 | A running program. Use `ps` to list processes. |
| **Daemon** | 守护进程 | A background process (like a Windows service). Example: sshd, httpd. |
| **Protocol** | 协议 | A set of rules for communication. HTTP, TCP, and DNS are all protocols. |
| **Packet** | 数据包 | The unit of data sent over a network. Wireshark captures packets. |
| **Bandwidth** | 带宽 | The maximum data transfer rate of a network connection. |
| **Latency** | 延迟 | The time it takes for data to travel from source to destination. |

## 第二阶段：网络原理

| 英文术语 | 中文翻译 | 安全语境中的含义 |
|----------|----------|-----------------|
| **OSI Model** | OSI模型 | A 7-layer conceptual model for network communication. "Please Do Not Throw Sausage Pizza Away". |
| **TCP/IP** | TCP/IP协议栈 | The actual protocol suite used on the internet. 4 layers: Application, Transport, Internet, Link. |
| **IP Address** | IP地址 | A numerical label assigned to each device. IPv4: 192.168.1.1, IPv6: 2001:db8::1. |
| **Subnet Mask** | 子网掩码 | Defines which part of an IP address is the "network" and which is the "host". |
| **MAC Address** | MAC地址 | A hardware address burned into the network card. 48 bits, written as 00:1A:2B:3C:4D:5E. |
| **DNS** | 域名系统 | Domain Name System — translates google.com → 142.250.80.46. |
| **HTTP** | 超文本传输协议 | HyperText Transfer Protocol — how browsers talk to web servers. |
| **HTTPS** | 安全的HTTP | HTTP over TLS/SSL — encrypts the connection. Look for the padlock icon. |
| **TLS/SSL** | 传输层安全协议 | Transport Layer Security — the encryption layer behind HTTPS. |
| **Port** | 端口 | A virtual "door" a service listens on. HTTP=80, HTTPS=443, SSH=22. |
| **Handshake** | 握手 | The initial negotiation between two devices. "TCP three-way handshake" = SYN → SYN-ACK → ACK. |
| **Proxy** | 代理 | A server that forwards requests on your behalf. Burp Suite acts as a proxy. |
| **Firewall** | 防火墙 | Filters incoming and outgoing network traffic based on rules. |
| **VPN** | 虚拟专用网络 | Virtual Private Network — creates an encrypted tunnel for your traffic. |

## 第三阶段：Web安全核心概念

| 英文术语 | 中文翻译 | 安全语境中的含义 |
|----------|----------|-----------------|
| **Vulnerability** | 漏洞 | A weakness that can be exploited. NOT the same as "exploit". |
| **Exploit** | 利用/攻击代码 | The actual code or technique used to take advantage of a vulnerability. |
| **Payload** | 有效载荷 | The "malicious part" of an exploit — the code that actually does the damage. |
| **Zero-day** | 零日漏洞 | A vulnerability unknown to the vendor. "Zero days since discovery." |
| **CVE** | 通用漏洞披露 | Common Vulnerabilities and Exposures — a unique ID for each known vulnerability. CVE-2024-xxxx. |
| **CVSS** | 通用漏洞评分系统 | Common Vulnerability Scoring System — rates severity from 0.0 to 10.0. |
| **OWASP** | 开放Web应用安全项目 | Open Web Application Security Project — publishes the famous "Top 10" list. |
| **Attack Vector** | 攻击向量 | The path or means by which an attacker gains access. |
| **Attack Surface** | 攻击面 | All the points where an attacker could try to enter. |
| **Threat Model** | 威胁模型 | A structured analysis of potential threats to a system. |
| **Penetration Testing** | 渗透测试 | Authorized simulated attack on a system to evaluate its security. |
| **Red Team / Blue Team** | 红队/蓝队 | Red=attackers (simulated), Blue=defenders. Purple=both working together. |
| **SOC** | 安全运营中心 | Security Operations Center — the team monitoring and defending an organization. |
| **SIEM** | 安全信息和事件管理 | Security Information and Event Management — aggregates and analyzes security logs. |

## 第四阶段：漏洞类型

| 英文术语 | 缩写 | 中文翻译 | 一句话理解 |
|----------|------|----------|-----------|
| **SQL Injection** | SQLi | SQL注入 | User input becomes part of a SQL query. |
| **Cross-Site Scripting** | XSS | 跨站脚本 | Attacker's JavaScript runs in victim's browser. |
| **Cross-Site Request Forgery** | CSRF | 跨站请求伪造 | Victim's browser performs unwanted actions on their behalf. |
| **Server-Side Request Forgery** | SSRF | 服务端请求伪造 | Trick the server into making requests to internal resources. |
| **Local File Inclusion** | LFI | 本地文件包含 | Read arbitrary files from the server. |
| **Remote File Inclusion** | RFI | 远程文件包含 | Include and execute code from a remote server. |
| **Remote Code Execution** | RCE | 远程代码执行 | The holy grail — run arbitrary commands on the target. |
| **Denial of Service** | DoS | 拒绝服务 | Make a service unavailable by overwhelming it. |
| **Privilege Escalation** | PrivEsc | 权限提升 | Go from a low-privilege user to root/admin. |
| **Man-in-the-Middle** | MITM | 中间人攻击 | Intercept (and potentially modify) communication between two parties. |
| **Buffer Overflow** | BoF | 缓冲区溢出 | Write data beyond the allocated memory buffer. |
| **Directory Traversal** | Path Traversal | 目录遍历 | Access files outside the web root (../../../etc/passwd). |
| **Insecure Direct Object Reference** | IDOR | 不安全直接对象引用 | Access others' data by changing an ID in the URL. |
| **XML External Entity** | XXE | XML外部实体注入 | Exploit XML parsers to read files or make requests. |
| **Server-Side Template Injection** | SSTI | 服务端模板注入 | Inject template code that gets executed on the server. |

| **Netcat (nc)** | The "Swiss army knife" of networking — read/write to TCP/UDP connections. |

## 📖 英文安全文档阅读三步法

结合你高考英语135分的能力，这是阅读英文安全文档的高效方法：

### 第一步：快速浏览（5分钟）
```
1. 看标题和摘要
2. 扫一遍小标题
3. 直接看代码/PoC（Proof of Concept）部分
4. 目的：判断这篇文章是否值得细读
```

### 第二步：精读关键部分（15-20分钟）
```
1. 仔细读 Vulnerability Details（漏洞详情）
2. 跟读 Impact（影响范围）
3. 理解 Exploitation Steps（利用步骤）
4. 不认识的术语查本速查表
```

### 第三步：实践验证（30分钟+）
```
1. 如果在本地能复现→动手复现
2. 如果不能复现→记录原理+截图保存
3. 用自己的话总结（中文或英文均可）
```

## 🎯 每日英文术语背诵法

每天从上面的术语表中选取5个，按以下格式记忆：

```
术语：Vulnerability
发音：/ˌvʌlnərəˈbɪləti/
助记：vulner（易受伤的）+ ability（能力）= 易受伤的地方 = 漏洞
一句话：A vulnerability is a weakness, an exploit is how you use it.
```
