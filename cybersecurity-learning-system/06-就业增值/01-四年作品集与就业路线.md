## 一、四年作品集搭建路线

### 什么是"安全作品集"？

面试官想看到的不是"我学过SQL注入"，而是"我能证明我会SQL注入"。

作品集就是你的**能力实物证明**，包括：
- 漏洞复现笔记
- SRC挖洞记录
- 开源工具/脚本
- CTF竞赛成绩
- 技术博客文章

### 大一：打基础的"零花钱"作品

| 作品类型 | 具体内容 | 产出目标 |
|----------|----------|----------|
| **学习笔记仓库** | 用GitHub建一个仓库，每天的学习笔记整理成Markdown上传 | 大一下学期前≥50篇笔记 |
| **靶场通关记录** | PortSwigger Academy每通过一个Lab，截图+写解题思路 | 完成50+Lab并记录 |
| **英文翻译贡献** | 翻译1-2篇安全相关的英文文章/Burp Suite官方文档 | 发表于GitHub或知乎 |
| **基础Python脚本** | 写几个实用小脚本：端口扫描器、目录爆破器、简单的HTTP请求工具 | GitHub上2-3个小项目 |

### 大二：上量的"正式作品"

| 作品类型 | 具体内容 | 产出目标 |
|----------|----------|----------|
| **SRC漏洞提交** | 在补天、漏洞盒子、CNVD等平台提交漏洞 | ≥10个有效漏洞 |
| **CVE漏洞复现** | 跟踪最新CVE公告，在本地搭建环境复现，写详细复现文档 | ≥15篇复现笔记 |
| **开源工具二开** | 在GitHub上找到感兴趣的安全工具，Fork后改进或增加功能 | 1-2个项目有实质贡献 |
| **自研小工具** | 开发一个完整的渗透测试辅助工具（如信息收集自动化脚本） | 1个项目达到可用水平 |

### 大三：面试级的"硬货作品"

| 作品类型 | 具体内容 | 产出目标 |
|----------|----------|----------|
| **SRC深度挖掘** | 针对特定厂商/系统进行深度测试，产出高质量漏洞报告 | ≥20个有效漏洞，其中≥3个高危 |
| **CTF竞赛经历** | 参加省级/国家级CTF竞赛（线上赛为主） | ≥3场比赛经历，有排名 |
| **技术文章** | 在FreeBuf、安全客、先知社区发表技术文章 | ≥3篇发表 |
| **毕业设计关联** | 毕设选题与Web安全相关（如"基于机器学习的XSS检测"等） | 毕设作品纳入作品集 |

### 作品集展示平台搭建

```
个人GitHub主页（最重要！）：
├── security-notes/          ← 学习笔记仓库
├── vuln-pocs/               ← 漏洞POC/复现
├── pentest-tools/           ← 自研/二开工具
├── ctf-writeups/            ← CTF比赛题解
└── awesome-security-list/   ← 资源整理（展示信息整合能力）

个人博客（可选）：
- GitHub Pages + Hexo/Hugo（免费）
- 知乎专栏
- 语雀/Notion公开页面

简历上的"项目经历"栏就是从这里提取的！
```

## 二、入门证书规划

### 证书选择的"三不原则"
1. ❌ **不考贵的**：OSCP（$1000+）等昂贵证书等你工作了再考虑
2. ❌ **不考没用的**：某些"花钱就能过的证书"校招面试官一眼识破
3. ✅ **只考高性价比的**：便宜+校招认可+有技术含量

### 推荐证书路线

| 阶段 | 证书 | 费用 | 考试形式 | 推荐理由 |
|------|------|------|----------|----------|
| 大一暑假 | **NISP一级** | 约480元 | 线上笔试 | 国家队认可，入门级，学生价低 |
| 大二 | **NISP二级** | 约4800元 | 线下机考 | 免试换CISP，校招安全岗广泛认可 |
| 大二-大三 | **CISP-PTE** | 学生价约2000元 | 线下实操 | 渗透测试方向专项认证，实操含金量高 |
| 大三（可选） | **软考-信息安全工程师** | 约150元 | 笔试 | 国家职称序列，考公/国企加分 |

> ⚠️ 注意：NISP一级仅限在校大学生报考。NISP二级持证后可免试换取CISP证书（CISP需要工作年限，但持NISP二级满3年可免试换证）。

### 证书优先级排序

```
必须考（性价比最高）：
  1. NISP一级（大一暑假）→ 2. NISP二级（大二）

锦上添花（有精力就考）：
  3. CISP-PTE → 4. 软考-信息安全工程师

工作了再说（现在不要考虑）：
  - OSCP（$1649，太贵）
  - CISSP（需要5年工作经验）
  - CISP（需要工作经验，有了NISP二级可以等）
```

## 三、安全竞赛入门路线

### CTF是什么？

CTF（Capture The Flag，夺旗赛）是网络安全领域的竞技比赛，相当于安全工程师的"编程竞赛"。

**比赛形式**：出题人故意在服务器/程序中留下漏洞，参赛者需要找到并利用漏洞获取"flag"（一串特殊字符串），提交flag得分。

### CTF五大方向

| 方向 | 英文 | 内容 | 适合你吗？ |
|------|------|------|-----------|
| Web安全 | Web | 网站漏洞利用 | ⭐⭐⭐⭐⭐ **主攻方向** |
| 逆向工程 | Reverse | 分析程序二进制代码 | ⭐ 需要汇编基础 |
| 密码学 | Crypto | 破解加密算法 | ⭐⭐ 需要数学基础 |
| 杂项 | Misc | 综合类、编码、隐写等 | ⭐⭐⭐ 有趣但非核心 |
| PWN | PWN | 二进制漏洞利用 | ⭐ 难度最高 |

### 入门路线

```
大一上学期：了解CTF
  → 注册CTFtime.org账号，关注近期比赛
  → 在BugKu（https://ctf.bugku.com）做新手题
  → 只做Web方向，先体验"解出题目的快感"

大一下学期：正式参赛
  → 参加1-2场线上CTF（如"网鼎杯"、"强网杯"的线上资格赛）
  → 目标是做出1-2道Web题，不是排名
  → 赛后阅读Writeup（别人的解题思路），积累经验

大二全年：有目的性地参加
  → 每学期至少1场CTF
  → 尝试不同题型，但仍以Web为主
  → 开始在GitHub上发布自己的Writeup
  → 可以找1-2个同学组队（一个人的力量有限）

大三：争取出成绩
  → 参加3+场比赛
  → 争取在省级/行业级比赛中获得名次
  → 比赛经历写入简历：列举比赛名称+解题数+排名百分比
```

### CTF入门资源

| 资源 | 链接/获取方式 | 说明 |
|------|-------------|------|
| CTFtime | https://ctftime.org | 全球CTF赛事日历 |
| BugKu | https://ctf.bugku.com | 中文在线CTF练习平台 |
| CTFHub | https://www.ctfhub.com | 按技能树分类的CTF训练平台 |

| 各赛事Writeup | GitHub搜索"CTF writeup" | 学习别人的解题思路 |

## 四、合规红线强制清单

> ⚠️ **网络安全学习的底线——记不住技术可以再学，触碰红线可能毁了整个人生。**

### ✅ 合法练习场景（绿灯区）

| 场景 | 具体平台/方式 |
|------|-------------|
| 本地靶场 | DVWA、Pikachu、Sqli-Labs、Vulhub等（安装在本地虚拟机中） |
| 授权在线靶场 | PortSwigger Web Security Academy、HackTheBox（需遵守平台规则） |
| CTF比赛环境 | 官方比赛提供的题目服务器 |
| SRC漏洞平台 | 补天、漏洞盒子、CNVD——仅在厂商授权的范围内测试 |
| 自行搭建的实验环境 | 自己写的代码、自己搭建的服务器 |
| 开源项目安全研究 | 在自己本地分析开源CMS/框架的代码漏洞 |

### ❌ 绝对禁止的行为（红线区）

| 禁止行为 | 法律后果 |
|----------|----------|
| **未经授权扫描/测试他人网站或服务器** | 《网络安全法》第27条：拘留+罚款+可能的刑事责任 |
| **利用漏洞获取他人数据（即使"只是看看"）** | 《刑法》第285条：非法获取计算机信息系统数据罪 |
| **传播、售卖漏洞利用工具** | 《刑法》第285条：提供侵入、非法控制计算机信息系统程序、工具罪 |
| **在未授权网站进行渗透测试（即使"好心"）** | 未经授权的渗透测试=非法入侵，无论动机 |
| **参与DDoS攻击、勒索软件传播** | 《刑法》第286条：破坏计算机信息系统罪 |
| **在论坛/群聊中分享非法入侵教程** | 可能构成传授犯罪方法罪 |
| **测试同校同学的设备/账号（未经明确授权）** | 即使是同学关系，未经授权也是违法的 |
| **使用他人WiFi进行安全测试（未获授权）** | 可能触犯非法控制计算机信息系统罪 |

### 🟡 需要特别注意的"灰色场景"

| 场景 | 正确做法 |
|------|----------|
| 发现一个网站有漏洞，想"帮忙修复" | ❌ 直接测试是违法的！→ ✅ 通过平台（CNVD、漏洞盒子）提交，由平台联系厂商 |
| 在GitHub上看到某网站的数据库配置信息 | ❌ 尝试连接是违法的！→ ✅ 通知网站管理员或提交到漏洞平台 |
| 同学让你帮忙"测试一下他们学校的教务系统" | ❌ 不是学校官方授权，就是违法的！→ ✅ 拒绝，并解释法律风险 |

### 📜 相关法律条文速记

```
《中华人民共和国网络安全法》
- 第27条：任何个人和组织不得从事非法侵入他人网络、
  干扰他人网络正常功能、窃取网络数据等危害网络安全的活动
- 第44条：任何个人和组织不得窃取或者以其他非法方式获取个人信息
- 第63条：违反第27条规定的，……处五日以下拘留，可以并处
  五万元以上五十万元以下罚款；……情节较重的，处五日以上
  十五日以下拘留，可以并处十万元以上一百万元以下罚款

《中华人民共和国刑法》
- 第285条：非法侵入计算机信息系统罪（三年以下）
- 第285条第2款：非法获取计算机信息系统数据罪（三年以下/三年以上七年以下）
- 第286条：破坏计算机信息系统罪（五年以下/五年以上）
```

### 🛡️ 安全从业者的基本职业道德

1. **技术能力越大，自律要求越高**——你懂的攻击手法比普通人多，更要管住手
2. **"我只是想学习"不是违法的理由**——学打枪要去靶场，学渗透要去授权靶场
3. **收到未授权漏洞线索时**：报告给平台，不要自己测试验证
4. **同事/同学提出违法请求时**：明确拒绝，解释法律风险
5. **技术分享时**：不教授非法入侵方法，只讨论授权靶场中的技术

|----------|----------|-------------|
