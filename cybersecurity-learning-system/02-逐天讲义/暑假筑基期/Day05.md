## 📖 通俗理论讲解

### 5.1 为什么安全工程师必须会命令行文本编辑器？

在安全测试中，你经常需要：
- 修改配置文件（如代理设置、工具参数）
- 查看和编辑日志文件
- 编写Python脚本（用于漏洞利用POC）
- 在没有图形界面的服务器上操作（远程SSH连接）

**图形编辑器（如记事本）= 需要鼠标、需要桌面 → 远程服务器没有这些！**
**命令行编辑器（Vim/Nano）= 只需要键盘 → 任何环境都能用。**

Vim是Linux世界最强大的文本编辑器，学习曲线略陡但学会终生受益。

---

### 5.2 Vim的三种模式——理解"模式"的概念

Vim和普通编辑器最大的不同：**它有模式**。

普通编辑器：打开→打字→Ctrl+S保存。始终处于"输入模式"。
Vim：你需要告诉它"我现在要移动光标"还是"我现在要打字"。

```
┌──────────────┐     按 i / a / o      ┌──────────────┐
│              │ ──────────────────▶    │              │
│  普通模式     │                       │  插入模式     │
│  (Normal)    │ ◀──────────────────    │  (Insert)    │
│  移动光标     │      按 Esc            │  打字编辑     │
│  复制粘贴     │                       │              │
│  删除        │                       │              │
└──────┬───────┘                       └──────────────┘
       │
       │ 按 : (冒号)
       ▼
┌──────────────┐
│  命令行模式    │
│  (Command)   │
│  :w 保存     │
│  :q 退出     │
│  :wq 保存退出 │
│  :q! 强制退出 │
└──────────────┘
```

**记忆口诀**：
- **普通模式 = 指挥官**：发号施令（移动、删除、复制）
- **插入模式 = 打字员**：负责输入文字（像普通编辑器）
- **命令行模式 = 后勤部**：保存、退出、搜索替换

---

### 5.3 文本处理命令的设计哲学——"管道"

Linux的设计哲学：每个命令只做好一件事。

但你想要复杂的功能时，怎么办？——**用管道 `|` 串联**。

```
命令A | 命令B | 命令C
  ↓       ↓       ↓
 产出    加工    再加工

类比：流水线工厂
工位1（生产）→ 工位2（筛选）→ 工位3（包装）
```

## 🔧 实操环节

### 实操1：Vim基础操作

#### 用Vim创建并编辑一个文件

```bash
cd ~/cybersec-practice
vim my-first-vim.txt
# 打开Vim编辑器（如果文件不存在会自动创建）
```

**进入Vim后，按以下步骤操作（跟着做就行，不要慌）：**

```
步骤1：你现在在"普通模式"
       试着按方向键（上下左右）——光标可以移动
       但你还不能打字（因为不在插入模式）

步骤2：按 i 键
       → 屏幕左下角显示 "-- INSERT --"
       → 恭喜！你现在在"插入模式"了！
       → 输入以下内容：

Today I learned Vim.
Vim has three modes: Normal, Insert, Command.
The normal mode is for navigation.
The insert mode is for typing.
The command mode starts with :

步骤3：按 Esc 键
       → "-- INSERT --" 消失
       → 你回到了"普通模式"

步骤4：按 :（冒号键，Shift + ;）
       → 屏幕左下角出现一个冒号 :
       → 你现在在"命令行模式"

步骤5：输入 wq 然后按回车
       → :wq = write and quit（写入并退出）
       → 文件已保存，回到终端！

步骤6：验证——查看文件内容
cat my-first-vim.txt
```

#### Vim常用快捷键速记

| 操作 | 按键 | 说明 |
|------|------|------|
| 进入插入模式 | `i` | 在光标前开始输入 |
| 进入插入模式（行尾） | `A` | 跳到行尾并进入插入模式 |
| 进入插入模式（下一行） | `o` | 在下面新建一行并进入插入模式 |
| 返回普通模式 | `Esc` | 任何情况下按Esc回到普通模式 |
| 删除一行 | `dd` | 在普通模式下按两次d |
| 撤销 | `u` | 在普通模式下按u |
| 复制一行 | `yy` | 在普通模式下按两次y |
| 粘贴 | `p` | 在普通模式下按p |
| 保存 | `:w` | 在命令行模式 |
| 退出 | `:q` | 在命令行模式 |
| 保存并退出 | `:wq` | 在命令行模式 |
| 不保存强制退出 | `:q!` | 在命令行模式 |

### 实操2：文本处理命令四件套

先准备一个练习用的文本文件：

```bash
cd ~/cybersec-practice

# 创建一个包含多行数据的文件
cat > access.log << 'EOF'
192.168.1.1 GET /index.html 200
10.0.0.5 POST /login 403
192.168.1.1 GET /admin 403
172.16.0.1 GET /index.html 200
10.0.0.5 GET /api/data 200
192.168.1.1 POST /login 401
172.16.0.1 GET /admin 403
10.0.0.5 GET /index.html 200
EOF
# 这是一份模拟的Web服务器访问日志
# 格式：IP地址 请求方法 请求路径 HTTP状态码
# EOF是结束标记，不是文件内容的一部分
```

#### 命令1：grep ——搜索文本

```bash
# grep = Global Regular Expression Print（全局正则表达式打印）
# 功能：在文本中搜索匹配的行

grep "403" access.log
# 搜索包含"403"的行（403=Forbidden，服务器拒绝访问）
# 输出所有403状态码的记录

grep "192.168.1.1" access.log
# 搜索包含这个IP地址的所有行
# 可以看某个IP的所有访问记录

grep -c "GET" access.log
# -c = count（计数）
# 输出：5  （有5行包含GET）

grep -v "200" access.log
# -v = invert（反转选择）
# 输出所有不包含"200"的行——找出所有非正常的请求

grep -i "POST" access.log
# -i = ignore case（忽略大小写）
# 这里大小写一样，但对于不确定大小写的场景很有用
```

#### 命令2：sort ——排序

```bash
# sort：对文本行排序

sort access.log
# 默认按字母顺序排序（数字也是按字符排，不是数值大小）
# 输出按每行第一个字符排序

sort -n access.log
# -n = numeric（按数值排序）
# 对第一个字段进行数值排序（如果第一个字段是数字）

sort -u access.log
# -u = unique（去重）
# 排序并去除重复行

sort -r access.log
# -r = reverse（逆序）
# 倒过来排序
```

#### 命令3：uniq ——去重

```bash
# uniq：去除连续重复的行（注意：只去重连续的！）

# 先看看原始数据
cat access.log

# 试图去重
uniq access.log
# 咦？好像没变化？因为重复的行不连续！

# 正确的做法：先排序，再去重
sort access.log | uniq
# | 是管道符——把sort的输出传给uniq
# 这样重复的行就相邻了，uniq才能正确去重

# -c = count（同时显示每行出现了几次）
sort access.log | uniq -c
# 输出每行前面有个数字，表示出现了几次
```

#### 命令4：wc ——计数

```bash
# wc = Word Count（单词计数）

wc access.log
# 输出：8 40 280 access.log
#      行数 单词数 字节数 文件名（这是虚拟数字，你实际可能不同）

wc -l access.log
# -l = lines（行数）
# 只显示行数

# 组合使用：统计有多少个403错误
grep "403" access.log | wc -l
# 先grep过滤出403的行，再用wc -l数有多少行
```

#### 进阶组合练习：管道实战

```bash
# 实战场景：分析访问日志，找出访问最多的IP地址

# 思路：
# 1. 提取每行的IP地址（第一个字段）
# 2. 排序（让相同的IP相邻）
# 3. 去重并计数
# 4. 按数字排序（count大的在前面）

awk '{print $1}' access.log | sort | uniq -c | sort -rn
# awk '{print $1}' → 取出每行的第一个字段（IP地址）
# sort → 排序让相同IP相邻
# uniq -c → 去重并统计每个IP出现次数
# sort -rn → 按数字逆序排序（次数多的在前面）

# 最终输出（样例）：
#       3 10.0.0.5
#       3 192.168.1.1
#       2 172.16.0.1
```

## 📋 今日知识点总结

| 编号 | 知识点 | 命令/概念 | 一句话说明 |
|------|--------|-----------|-----------|
| 1 | Vim三种模式 | Normal/Insert/Command | 普通移动，插入打字，命令保存退出 |
| 2 | 进入插入 | `i` | 在光标处开始打字 |
| 3 | 保存退出 | `:wq` | 写入并退出 |
| 4 | 强制退出 | `:q!` | 放弃修改，强制退出 |
| 5 | grep | `grep "关键词" 文件` | 搜索文本 |
| 6 | sort | `sort 文件` | 排序 |
| 7 | uniq | `sort 文件 \| uniq -c` | 去重（通常先排序） |
| 8 | wc | `wc -l 文件` | 统计行数/单词数/字节数 |
| 9 | 管道 | `命令A \| 命令B` | 把A的输出传给B处理 |
