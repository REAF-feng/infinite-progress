## 第2周：Linux进阶与网络入门（Day08-14）

### Day08：软件包管理与进程操作
- **理论**：apt包管理器原理、Linux进程概念、前台/后台运行
- **实操**：`apt install/search/remove`、`ps aux`、`top`、`kill`、`&` 后台运行
- **资源**：`man apt`、搜索"Linux process management tutorial"

### Day09：网络基础概念
- **理论**：什么是网络？局域网vs广域网、IP地址的作用（生活类比：门牌号）
- **实操**：`ip addr`、`ifconfig`、`ping`、理解输出信息的含义
- **资源**：CrashCourse Computer Networks #1

### Day10：Shell脚本入门(上)
- **理论**：什么是脚本？#!/bin/bash的含义、变量、echo
- **实操**：创建第一个Shell脚本、用变量存储信息、`chmod +x` 执行
- **资源**：搜索"Bash scripting tutorial for beginners"

### Day11：Shell脚本入门(下)
- **理论**：条件判断(if/else)、循环(for/while)、用户输入(read)
- **实操**：编写系统信息收集脚本（CPU、内存、磁盘一屏显示）
- **资源**：`man bash`（虽然很长，但学会用`/`搜索关键词）

### Day12：数据流重定向与管道进阶
- **理论**：stdin(0)/stdout(1)/stderr(2)、`>` `>>` `<` `|` 本质
- **实操**：`2>&1` 合并错误输出、`tee` 同时输出到屏幕和文件
- **资源**：搜索"Linux stdin stdout stderr explained"

### Day13：文件查找与正则表达式入门
- **理论**：正则表达式（regex）基本语法——`.` `*` `[]` `^` `$`
- **实操**：`find` 按名称/类型/时间查找、`grep -E` 使用正则搜索
- **资源**：regex101.com（在线正则练习工具）

### Day14：第二周复习+测评
- **复习**：Linux命令体系梳理（40+条命令分类总结）
- **考核**：Shell脚本编写任务、文件操作+文本处理综合题
- **资源**：回顾Day08-13笔记，补缺补漏

## 第3周：网络原理(上)——数据如何传输（Day15-21）

### Day15：网络是什么+OSI七层模型(上)
- **理论**：网络发展简史、OSI七层模型总览（"Please Do Not Throw Sausage Pizza Away"）
- **关键概念**：物理层(网线/光纤)、数据链路层(MAC地址/交换机)
- **实操**：`ip link` 查看网卡MAC地址
- **资源**：CrashCourse Computer Networks #2-3

### Day16：OSI七层模型(下)+TCP/IP协议栈
- **理论**：网络层、传输层、会话层、表示层、应用层；TCP/IP四层模型与OSI的对应关系
- **关键概念**：为什么OSI七层但实际用TCP/IP四层？
- **实操**：画OSI和TCP/IP对照图，标注每层代表性协议
- **资源**：搜索"OSI model vs TCP/IP model"

### Day17：IP地址深度理解
- **理论**：IPv4地址结构（32位，分4段）、公网IP vs 私网IP、NAT转换
- **关键概念**：192.168.x.x = 你家内部门牌号，公网IP = 小区地址
- **实操**：`ip addr` 详细解读输出、查看自己的公网IP
- **资源**：搜索"What is an IP address explained simply"

### Day18：子网掩码与CIDR
- **理论**：子网掩码的作用（区分"网络号"和"主机号"）、CIDR表示法
- **关键概念**：255.255.255.0 = /24 = 前24位是网络号，后8位是主机号
- **实操**：手动计算子网范围（192.168.1.0/24 → 可用IP：192.168.1.1-254）
- **资源**：搜索"subnet mask calculator"（在线计算器辅助理解）

### Day19：路由与交换基础
- **理论**：交换机(同一网络内通信)、路由器(不同网络间通信)、默认网关
- **关键概念**：你家路由器=交换机+路由器+NAT合体
- **实操**：`ip route` 查看路由表、`traceroute` 跟踪数据包路径
- **资源**：搜索"How does a router work"

### Day20：ARP协议与局域网通信
- **理论**：ARP（地址解析协议）——通过IP找到MAC地址的过程
- **关键概念**：ARP请求=大声喊"谁是192.168.1.5？"→目标回应"是我，MAC是XX"
- **实操**：`ip neigh` 查看ARP表、Wireshark抓取ARP包分析
- **资源**：搜索"ARP protocol explained"

### Day21：第三周复习+测评
- **复习**：OSI七层→TCP/IP四层→IP→子网→路由完整知识链
- **考核**：理论卷（选择+简答+网络拓扑分析题）
- **资源**：整理本周网络术语（建议做成Anki卡片）

## 第4周：网络原理(下)——应用层协议（Day22-28）

### Day22：传输层——TCP协议详解
- **理论**：TCP三次握手(SYN→SYN-ACK→ACK)、四次挥手、可靠传输机制
- **关键概念**：TCP像"挂号信"——必须签收确认；UDP像"普通信"——扔出去不管
- **实操**：Wireshark抓取一次TCP握手全过程，标注SYN/ACK标志位
- **资源**：搜索"TCP three way handshake animation"

### Day23：DNS——互联网的电话簿
- **理论**：域名→IP的查询过程（递归/迭代查询）、DNS记录类型(A/AAAA/CNAME/MX/NS)
- **关键概念**：DNS查询像查电话簿——输入人名(域名)，输出号码(IP)
- **实操**：`nslookup`、`dig` 查询DNS记录、修改`/etc/hosts`理解域名解析顺序
- **资源**：搜索"How DNS works"（有一张著名漫画图解）

### Day24：HTTP协议(上)——请求与响应
- **理论**：HTTP请求方法(GET/POST/PUT/DELETE)、URL结构、请求头/响应头
- **关键概念**：HTTP是浏览器和服务器之间的"对话语言"
- **实操**：浏览器F12→Network→访问网站→分析每个HTTP请求的Request/Response
- **资源**：MDN Web Docs "An overview of HTTP"（英文，极好的阅读材料）

### Day25：HTTP协议(下)——状态码、Cookie、Session
- **理论**：状态码分类(2xx成功/3xx重定向/4xx客户端错/5xx服务端错)、Cookie vs Session
- **关键概念**：Cookie=餐厅给你的号码牌，Session=餐厅记录的"3号桌已点菜"
- **实操**：浏览器查看Cookie(F12→Application→Cookies)、用curl -v 看完整请求头
- **资源**：搜索"HTTP cookies explained"

### Day26：HTTPS与TLS加密
- **理论**：对称加密vs非对称加密、TLS握手过程、证书与CA、中间人攻击
- **关键概念**：HTTPS=HTTP外面包了一层加密壳(TLS)
- **实操**：浏览器点击地址栏的🔒→查看证书信息、Wireshark对比HTTP和HTTPS包
- **资源**：搜索"How HTTPS works"（漫画图解）

### Day27：Wireshark实战抓包分析
- **理论**：Wireshark界面布局、过滤器语法、追踪流
- **实操**：抓取HTTP请求→过滤→追踪HTTP流→导出为文本；抓DNS查询→看问答过程
- **资源**：Wireshark官方用户指南（前3章）
- **过滤器速记**：`http` `dns` `tcp.port==80` `ip.addr==192.168.1.1`

### Day28：第四周复习+测评
- **复习**：TCP握手→DNS查询→HTTP请求→HTTPS加密 完整数据流
- **考核**：Wireshark实战抓包分析题——给一个pcap文件，回答问题
- **资源**：整理"一个URL从输入到页面显示经历了什么"的完整流程

## 第6周：安全入门——漏洞第一课（Day36-42）

### Day36：网络安全概述
- **理论**：什么是"安全"？CIA三要素(机密性/完整性/可用性)、攻击者类型
- **关键概念**：安全不是加锁，是"不断评估风险→采取措施→再评估"的循环
- **实操**：阅读OWASP TOP10 (2021) 概览页（英文原文）
- **资源**：OWASP官网 owasp.org/www-project-top-ten/

### Day37：信息收集(Reconnaissance)
- **理论**：被动信息收集vs主动信息收集、Google Hacking、WHOIS查询
- **实操**：用 `whois` 查询域名注册信息、用Google搜索语法（site:/inurl:/intitle:）
- **资源**：搜索"Google hacking database"

### Day38：DVWA环境搭建+第一个漏洞
- **理论**：什么是靶场？DVWA四种安全级别（Low/Medium/High/Impossible）
- **实操**：搭建DVWA完整环境→设为Low安全级别→进入Brute Force模块
- **资源**：DVWA官方GitHub README

### Day39：暴力破解(Brute Force)
- **理论**：字典攻击vs暴力破解、HTTP Basic认证、Burp Suite Intruder基础
- **实操**：DVWA Brute Force(Low)——用Burp Suite抓包→Intruder→用密码字典破解
- **资源**：PortSwigger "Burp Suite Intruder tutorial"

### Day40：命令注入(Command Injection)
- **理论**：系统命令拼接(`;` `&&` `|`)、输入过滤失效
- **实操**：DVWA Command Injection(Low/Medium)——ping功能注入额外命令
- **资源**：OWASP "Command Injection" 页面

### Day41：CSRF(跨站请求伪造)
- **理论**：无意识请求、Cookie自动携带、攻击链条
- **实操**：DVWA CSRF(Low)——构造恶意页面，诱导点击修改密码
- **资源**：PortSwigger Academy "CSRF" 章节

### Day42：第六周复习+测评
- **复习**：安全概念→信息收集→暴力破解→命令注入→CSRF
- **考核**：理论+DVWA对应4个漏洞实操闯关（限时90分钟）
- **资源**：制作"漏洞原理对比表"（每种漏洞：触发条件、利用方法、防御措施）

## 第7周：Web漏洞实操进阶（Day43-49）

### Day43：XSS反射型(Reflected XSS)
- **理论**：反射型XSS原理（恶意脚本藏在URL中）、`<script>alert(1)</script>`
- **实操**：DVWA XSS(Reflected) Low/Medium/High三种级别全通关
- **资源**：PortSwigger Academy "Reflected XSS" Lab

### Day44：XSS存储型(Stored XSS)
- **理论**：存储型XSS原理（恶意脚本存在服务器中）、危害远大于反射型
- **实操**：DVWA XSS(Stored)全级别通关、理解为什么High级别用htmlspecialchars
- **资源**：PortSwigger Academy "Stored XSS" Lab

### Day45：SQL注入(上)——基础注入
- **理论**：SQL语句回顾、数字型注入vs字符型注入、`' OR '1'='1` 万能密码
- **实操**：DVWA SQL Injection(Low)——手工注入获取所有用户数据
- **资源**：PortSwigger Academy "SQL Injection"（推荐全部Lab）

### Day46：SQL注入(下)——UNION注入与信息收集
- **理论**：UNION SELECT注入、information_schema、获取库名/表名/列名
- **实操**：DVWA SQL Injection(Medium)——用UNION查询获取数据库结构
- **资源**：搜索"SQL injection UNION attack tutorial"

### Day47：文件上传(File Upload)
- **理论**：Webshell概念、前端验证绕过、MIME类型绕过、扩展名绕过
- **实操**：DVWA File Upload(Low/Medium)——上传PHP Webshell并用浏览器访问
- **资源**：OWASP "Unrestricted File Upload"

### Day48：文件包含(File Inclusion)
- **理论**：LFI(本地文件包含)/RFI(远程文件包含)、`../../../` 路径穿越
- **实操**：DVWA File Inclusion(Low/Medium)——读取/etc/passwd
- **资源**：搜索"Local File Inclusion exploitation guide"

### Day49：第七周复习+测评
- **复习**：XSS(反射+存储)→SQL注入(基础+UNION)→文件上传→文件包含
- **考核**：DVWA全部漏洞模块综合闯关（随机抽4个漏洞，限时2小时）
- **资源**：制作"漏洞利用步骤卡"——每种漏洞的标准化利用流程
