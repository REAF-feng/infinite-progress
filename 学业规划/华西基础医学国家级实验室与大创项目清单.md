# 华西基础医学本科可参与的国家级实验室与大创项目清单

> **适用对象**：四川大学华西基础医学与法医学院本科生（大一至大三），目标积累科研经历、产出可发表的实验数据、为欧洲PhD申请建立实验室技能profile。
>
> **核心逻辑**：华西拥有西部最大的生物医学研究集群。本科生的核心竞争力不在于"学校名字"而在于"你加入了哪个实验室→学会了什么技术→产出了什么结果"。本清单帮助你在大一就开始了解这些资源。

---

## 一、华西基础医学相关国家级/省部级实验室全景

### 1.1 生物治疗国家重点实验室（SKLB）

| 维度 | 信息 |
|:---|:---|
| **级别** | 国家重点实验室（全国生物治疗领域排名前3） |
| **位置** | 华西校区（大三后可高频进入） |
| **核心方向** | 肿瘤免疫治疗、基因治疗、干细胞治疗、天然产物药物开发 |
| **本科生可参与性** | ⭐⭐⭐⭐（多个课题组开放本科生） |
| **对欧洲PhD申请的匹配度** | ⭐⭐⭐⭐⭐（全方向完美匹配） |
| **代表性课题组（供参考）** | 肿瘤免疫微环境、CAR-T/TCR-T细胞治疗、CRISPR基因编辑、小分子靶向药物筛选 |
| **进组渠道** | 通过基础医学专业课程教师引荐 / 学院科研导师制度 / 主动联系PI |
| **建议进组时间** | 大一下（先观察）→ 大二上（成为正式成员） |

**本科生在该实验室的典型科研pathway**：
```
大一：观摩实验 + 学习基础操作（配试剂/细胞培养）
大二：独立承担1个子课题（如"XX基因在肿瘤细胞中的表达验证"）→ 申报大创
大三：深入课题 + 产出数据 → 写论文初稿 → 投稿
大四：论文修回/发表 + 毕业论文在该实验室完成
```

## 二、本科生可参与的科研项目清单（按时间排列）

### 2.1 大学生创新训练项目（大创）

| 维度 | 详细信息 |
|:---|:---|
| **级别** | 国家级 / 省级 / 校级三级 |
| **申报时间** | 每年11月–次年3月（学院初审→学校评审→省级立项→国家级推荐） |
| **执行周期** | 1–2年（一般大二上申报，大二下–大三执行，大三下–大四上结题） |
| **经费** | 国家级约¥8,000–20,000 / 省级约¥5,000–10,000 / 校级约¥2,000–5,000 |
| **要求** | 3–5人小组，1位指导教师，有完整申报书、中期报告、结题报告 |
| **对欧洲PhD申请的价值** | ⭐⭐⭐⭐（省级+大创="有独立课题经验"的行内证明） |
| **冲刺目标** | 国家级立项+负责人 |

**大创申报全流程时间表**：

| 时间 | 任务 | 操作细节 |
|:---|:---|:---|
| 大一下 5–6月 | 确定课题方向+导师 | 在课题组现有研究框架内选择"可1年内完成的子课题" |
| 大一下 7–8月（暑假） | 写申报书初稿 | 含：立题依据（背景+科学问题+意义）、研究内容（3–4个核心实验）、技术路线（流程图）、预期成果、经费预算 |
| 大二上 9–10月 | 导师审阅+修改 | 导师会帮你把关"做不做得完"和"创新点够不够" |
| 大二上 11月 | 学院初审+提交 | 注意学院通知和截止时间 |
| 大二上 12月–大二下 1月 | 校级评审 | 等待结果 |
| 大二下 2–3月 | 公布立项结果 | 如立项成功，立刻制定详细实验时间表 |
| 大二下–大三上 | 执行实验 | 按申报书的技术路线推进，每月向导师汇报 |
| 大三上 | 中期检查 | 提交中期报告+初步数据 |
| 大三下–大四上 | 项目结题 | 结题报告+答辩 |

## 三、科研资源配置策略（按年级推荐）

### 大一篇：基础平台入门

| 优先级 | 资源 | 行动 |
|:---|:---|:---|
| 🥇 第一优先 | 华西基础医学实验教学示范中心 | 通过课程实验学习基础操作规范 |
| 🥈 第二优先 | 生物治疗国家重点实验室（SKLB） | 浏览官网→筛选课题组→大一下进组 |
| 🥉 第三优先 | 学院导师办公室 | 了解哪些导师愿意带本科生+有哪些在研课题 |

**大一底线**：进1个课题组（任一实验室均可），每周在实验室≥6小时

### 大二篇：课题突破+项目申报

| 优先级 | 资源 | 行动 |
|:---|:---|:---|
| 🥇 第一优先 | 大创项目申报 | 在课题组确定选题→11月申报→目标省级+ |
| 🥈 第二优先 | 华西-德国暑期交换 | 3–5月申请→7–8月执行→锁定外方推荐信 |
| 🥉 第三优先 | 生物治疗国家重点实验室（SKLB）（如果大一的课题组不在此） | 评估是否需要在大二更换到产出更好的课题组 |

**大二底线**：大创省级+立项（负责人）+ 暑期交换成功或同级别替代项目

### 大三篇：数据产出+会议展示

| 优先级 | 资源 | 行动 |
|:---|:---|:---|
| 🥇 第一优先 | 大创结题+论文初稿 | 整理所有数据→写论文→与导师讨论投稿 |
| 🥈 第二优先 | 基础医学创新论坛/挑战杯 | 用大创数据参赛→全国展示 |
| 🥉 第三优先 | 全国学术会议（中国免疫学会/病理生理学会年会等） | 投会议摘要→做海报展示 |

**大三底线**：会议展示≥1次 + 论文初稿完成（或综述已投稿）

## 四、选择课题组的检查清单

选择课题组（尤其是大一的第一个课题组）时，逐项核对以下标准：

| # | 检查项 | 判断标准 | ✓ |
|:---|:---|:---|:---|
| 1 | 近2年是否有SCI产出 | 在PubMed搜索导师姓名→应有连续论文 | ☐ |
| 2 | 论文IF水平 | IF≥5的论文存在（说明实验体系成熟） | ☐ |
| 3 | 是否带过本科生发论文 | 看近2年论文的作者列表→是否有本科生 | ☐ |
| 4 | 组内氛围 | 向学长学姐打听导师是否"肯教""不卡人" | ☐ |
| 5 | 实验平台 | 课题组是否有WB/细胞培养/流式/组化常用设备（不需要每次都去公共平台排队） | ☐ |
| 6 | 英语使用频率 | 组会是否有时用英语/论文是否英文发表 | ☐ |
| 7 | 组会频率 | 每周1次组会是最理想的节奏（太少=放养，太多=过度消耗） | ☐ |
| 8 | 研究方向匹配度 | 课题组方向是否属于肿瘤免疫/神经退行/分子病理/药理这四条赛道之一 | ☐ |

> **红灯预警**（满足任一条件应慎重考虑）：
> - 导师近2年无SCI论文产出
> - 导师已转行政岗（副院长/处长等）不再亲自带学生
> - 学长学姐评价为"不管学生""压人不让毕业""组内氛围差"
> - 课题组主要方向是法医学（与欧洲PhD不匹配）
