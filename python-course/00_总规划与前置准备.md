## 二、前置准备：电脑环境安装（Windows）

> ⚠️ **不用担心"环境配置"这个词**——它就像你玩手机游戏前要去应用商店下载App一样，是一次性的准备工作，跟着下面步骤一步步来就行。

### 第一步：安装Python（给电脑装上"翻译官"）

Python就像是你和电脑之间的翻译官。你说"print('你好')"，Python翻译给电脑听，电脑就在屏幕上显示"你好"。

**操作步骤：**

1. 打开浏览器（你平时上网的那个软件，比如Edge浏览器）
2. 在地址栏输入：`https://www.python.org/downloads/`
3. 你会看到一个黄色的大按钮，写着"Download Python 3.x.x"，点它下载
4. 下载完成后，双击打开安装文件
5. **⚠️ 最重要的一步！** 在安装窗口的**最下面**，有一个小方框写着"Add Python to PATH"（把Python加入系统路径），**一定要勾选它！**（不勾的话后面会很麻烦）
6. 勾选后，点击"Install Now"（立即安装）
7. 等进度条走完，显示"Setup was successful"就完成了

**验证安装是否成功：**

按下键盘上的 `Win键 + R`（Win键就是键盘左下角那个带Windows图标的键），会弹出一个小窗口，输入 `cmd` 然后回车。

在弹出的黑色窗口里输入：
```
python --version
```
然后按回车。如果看到类似 `Python 3.12.0` 这样的文字，恭喜你，安装成功！

> 🔧 **如果提示"'python'不是内部或外部命令"**：说明你忘了勾选"Add Python to PATH"。重新安装一遍，这次记得勾选那个小方框。

### 第二步：安装VS Code（给你一个"写字板"）

写Python代码需要一个"写字软件"，就像写作文需要Word一样。我们用VS Code（全名Visual Studio Code），它是免费的、好用的、功能强大的代码编辑器。

**操作步骤：**

1. 打开浏览器，输入：`https://code.visualstudio.com/`
2. 点击蓝色大按钮"Download for Windows"下载
3. 双击安装文件，一路点"下一步"就行（全部默认选项即可）
4. 安装完成后打开VS Code

**安装中文语言包（可选但推荐）：**

1. 打开VS Code后，看左边竖着的那一排小图标
2. 点击那个由四个小方块组成的图标（叫"扩展商店"）
3. 在搜索框输入"Chinese"
4. 找到"Chinese (Simplified) Language Pack"，点击"Install"
5. 安装完右下角会弹出提示问你要不要重启，点"Restart"重启即可

**安装Python扩展（必须装）：**

1. 同样在扩展商店里搜索"Python"
2. 找到微软官方出的那个（发布者是Microsoft），点击"Install"
3. 等待安装完成即可

### 第三步：创建你的第一个Python文件

1. 在电脑桌面上新建一个文件夹，命名为 `python学习`
2. 打开VS Code，点击左上角"文件"→"打开文件夹"，选择刚才建的`python学习`文件夹
3. 在VS Code左边文件列表区域右键→"新建文件"，命名为 `day01.py`
4. 在右侧编辑区输入下面这行代码：
```python
print("你好，Python！我是小明")
```
5. 按 `Ctrl + S` 保存
6. 点击右上角的 ▶ 三角形按钮（运行按钮）
7. 看下方弹出的"终端"窗口，如果显示"你好，Python！我是小明"，恭喜你完成了第一个程序！

> 🎉 **到这里，你的电脑已经完全准备好学习Python了！**

## 三、学习规则说明

### 📗 必学内容（每天都要完成）
- 每天1篇讲课文稿（预计30分钟阅读+理解）
- 当天课后基础巩固题（预计20分钟）
- 当天课后进阶实操题（预计25分钟）
- 填写每日打卡（预计5分钟）

### 📘 拓展选学内容（学有余力再做）
- 拓展思考题（难度较高，可以放到周末集中攻克）
- 文中标注"⭐拓展"的额外知识点
- 每个阶段结束后的"自由练手小项目"

### ⚠️ 小白高频误区 TOP 10

| 序号 | 误区 | 正确理解 |
|------|------|----------|
| 1 | 英文符号和中文符号混用 | 写代码时**所有符号必须是英文状态**输入，中文的括号（）、引号""、冒号：程序都不认识 |
| 2 | 以为学Python要背所有英文单词 | 不需要！常用的就几十个，写着写着就记住了，忘了随时查 |
| 3 | 空格和缩进随便打 | Python对缩进（行首空格）非常严格，该空4格必须空4格，否则报错 |
| 4 | 只看不写代码 | 编程是"肌肉记忆"，看10遍不如自己敲1遍，务必手打代码 |
| 5 | 遇到报错就慌 | 报错是好朋友，它在告诉你哪里出问题了。学会看最后一行报错信息 |
| 6 | 想一次性学完所有知识 | 贪多嚼不烂，每天1.5小时正好，超额反而容易放弃 |
| 7 | 变量名随便起，比如a、b、c | 起有意义的名字，比如`student_name`比`s`好理解100倍 |
| 8 | 不保存文件就运行 | 每次修改代码后先`Ctrl+S`保存，再运行 |
| 9 | 复制粘贴代码 | 初期一定要手打！手打过程会让你注意到每个细节 |
| 10 | 觉得自己学不会 | 每个程序员都是从零开始的，没有人天生会写代码 |
