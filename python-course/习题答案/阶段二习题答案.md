## Day 11

**题1：** 输出 `A`（x=10，外层x>5成立，内层x>8也成立）

**题2：**
```python
if a == b and b == c:     # 等边
elif a == b or b == c or a == c:   # 等腰
```

**题3（思路）：** 嵌套if结构，先判断是否住户→再判断年龄；非住户判断是否有访客码。

**题4（参考答案）：**
```python
distance = float(input("里程(公里)："))
wait = float(input("等待时间(分钟)："))
# 等待时间折算
total_km = distance + wait / 5
# 计费
if total_km <= 3:
    cost = 8
elif total_km <= 15:
    cost = 8 + (total_km - 3) * 1.5
else:
    cost = 8 + 12 * 1.5 + (total_km - 15) * 2.3
print(f"总费用：{cost:.2f}元")
```

## Day 13

**题1：** 输出2行，每行3个星号 `***` 换行 `***`

**题2：**
```python
for row in range(5, 0, -1):
    for col in range(row):
        print("*", end="")
    print()
```

**题3（思路）：** 分上半部分（1,3,5,7个）和下半部分（5,3,1个）分别用for循环。

**题4：** 类似九九乘法表，把乘号改成加号。

**题5（参考答案）：**
```python
for x in range(0, 21):       # 公鸡最多20只(100/5)
    for y in range(0, 34):   # 母鸡最多33只(100/3)
        z = 100 - x - y      # 小鸡数量
        if 5*x + 3*y + z/3 == 100:
            print(f"公鸡{x}只，母鸡{y}只，小鸡{z}只")
```

**题1：** 输出 `1 2 4`（跳过3，到5时break）

**题2：**
```python
if num > 100:
    print(f"找到了：{num}")
```

**题3（参考答案）：**
```python
n = int(input("请输入一个正整数："))
for i in range(2, int(n**0.5)+1):
```
