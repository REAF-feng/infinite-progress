**题5（参考答案）：**
```python
num = int(input("请输入一个正整数："))
reversed_num = 0
while num > 0:
    last_digit = num % 10
    reversed_num = reversed_num * 10 + last_digit
    num = num // 10
print(f"反转后：{reversed_num}")
```

## Day 09

**题1：** `0,1,2,3`、`2,3,4,5`、`0,3,6,9`

**题2：** 输出3行"你好"

**题3（参考答案）：**
```python
odd_sum = 0
even_sum = 0
for num in range(1, 101):
    if num % 2 == 0:
        even_sum += num
    else:
        odd_sum += num
print(f"奇数和：{odd_sum}，偶数和：{even_sum}")
```

**题4（参考答案）：**

```python
for i in range(1, 10):

```

**题5（参考答案）：**
```python
for num in range(100, 1000):
    hundreds = num // 100
    tens = (num // 10) % 10
    ones = num % 10
    if hundreds**3 + tens**3 + ones**3 == num:
        print(num)
# 输出：153, 370, 371, 407
```
