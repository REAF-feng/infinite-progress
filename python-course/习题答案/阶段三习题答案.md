**题3（参考答案）：**
```python
scores = []
while True:
    user_input = input("输入成绩（q退出）：")
    if user_input == "q":
        break
    try:
        score = float(user_input)
        scores.append(score)
    except ValueError:
        print("请输入数字！")
if scores:
    print(f"平均分：{sum(scores)/len(scores):.1f}")
    print(f"最高分：{max(scores)}，最低分：{min(scores)}")
```

**题4（思路）：** 用while循环+列表的append/remove/clear方法。

**题5（参考答案）：**
```python
nums = input("输入数字用空格分隔：").split()
seen = []
for n in nums:
    if n not in seen:
        seen.append(n)
print("去重后：", seen)
```
