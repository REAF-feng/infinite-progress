**题3（参考答案）：**
```python
def smart_print(*items, sep=", ", end="\n"):
    output = sep.join(str(item) for item in items)
    print(output, end=end)
```

**题4（思路）：** 用 `**info` 接收任意参数，append到全局列表。

**题5（思路）：** 
```python
def calculate(operation, *args, **options):
    if operation == "sum":
        result = sum(args)
    elif operation == "product":
        result = 1
        for n in args: result *= n
    elif operation == "average":
        result = sum(args) / len(args)
    precision = options.get("precision", 2)
    return round(result, precision)
```
