## 📖 知识点讲解

### 1. 字典是什么？

字典用**大括号 `{}`**，但它和集合不同——字典里存的是**键值对**。

```python
# 列表：按位置访问
student = ["小明", 18, "男", 175]
# 问题：索引0存的是什么？得记住！

# 字典：按名字访问
student = {"姓名": "小明", "年龄": 18, "性别": "男", "身高": 175}
# 很清楚！student["姓名"] 就知道是"小明"
```

**生活类比：** 
- 列表像电影院座位（第1排第3座，按编号找）
- 字典像查字典（知道"apple"这个词就能找到它的意思，按"词条"找）

### 2. 字典结构

```python
字典 = {
    "键1": "值1",     # 一个键值对
    "键2": "值2",     # 键和值用冒号连接
    "键3": "值3",     # 键值对之间用逗号分隔
}
```

**规则：** 键必须唯一（不能重复），值可以重复。

## 💻 课堂演示代码

```python
# ========== 创建字典 ==========

# 方式1：直接写
person = {
    "name": "小明",
    "age": 18,
    "city": "北京",
    "hobby": "编程"
}

# 方式2：dict()函数
empty_dict = {}                    # 空字典
scores = {"语文": 85, "数学": 92, "英语": 78}

print("个人信息：", person)
print("成绩单：", scores)

# ========== 访问值 ==========

print("姓名：", person["name"])     # 用键访问值
print("年龄：", person["age"])

# .get() 更安全，键不存在时不报错
print("电话：", person.get("phone", "未填写"))  # 键不存在，返回默认值

# ========== 修改和添加 ==========

person["age"] = 19                 # 修改已有的键
print("修改后年龄：", person["age"])

person["phone"] = "13800138000"    # 添加新的键值对
print("添加电话后：", person)

# ========== 删除 ==========

del person["phone"]                # 删除键值对
print("删除电话后：", person)

popped = person.pop("hobby")       # 弹出并删除
print("弹出的值：", popped)

# ========== 遍历字典 ==========

print()
print("=== 遍历所有键值对 ===")
for key, value in person.items():
    print(f"{key} → {value}")

print()
print("=== 遍历所有键 ===")
for key in person.keys():
    print(key, end="  ")

print()
print("=== 遍历所有值 ===")
for value in person.values():
    print(value, end="  ")

# ========== 检查键是否存在 ==========

if "name" in person:
    print("\n姓名已填写")             # 会输出
if "email" not in person:
    print("邮箱未填写")               # 会输出

# ========== 字典的长度和清空 ==========

print("字典元素个数：", len(person))  # 4
# person.clear()                     # 清空字典（慎用！）
```

## 📝 本节课核心知识点总结

| 序号 | 知识点 | 一句话记忆 |
|------|--------|------------|
| 1 | 字典 `{键:值}` | 像查字典一样，通过键找到值 |
| 2 | `dict["键"]` | 根据键获取值，键不存在会报错 |
| 3 | `.get("键",默认值)` | 更安全的取值方式 |
| 4 | `dict["新键"] = 值` | 添加或修改键值对 |
| 5 | `.items()` | 同时遍历键和值 |
| 6 | `.keys()` `.values()` | 分别遍历键或值 |
| 7 | `"键" in dict` | 检查键是否存在 |
