## 📖 知识点讲解

### 1. 为什么需要嵌套？

现实中的数据往往是嵌套的：
- 一个班级里有多个学生（每个学生是一个字典）
- 一个通讯录里有多个联系人
- 一个订单里有多个商品

**字典 + 列表 组合可以表示几乎任何数据结构！**

### 2. 常见嵌套模式

```python
# 字典里放列表
students = {
    "一班": ["小明", "小红", "小刚"],
    "二班": ["小丽", "小强", "小军"]
}

# 列表里放字典（最常用！）
contacts = [
    {"name": "张三", "phone": "138xxx", "city": "北京"},
    {"name": "李四", "phone": "139xxx", "city": "上海"},
]

# 字典里放字典
school = {
    "一班": {"班主任": "王老师", "人数": 45},
    "二班": {"班主任": "李老师", "人数": 42},
}
```

## 💻 课堂演示代码

```python
# ========== 列表嵌套字典：通讯录 ==========

contacts = [
    {"姓名": "张三", "电话": "13800001111", "城市": "北京", "年龄": 25},
    {"姓名": "李四", "电话": "13800002222", "城市": "上海", "年龄": 30},
    {"姓名": "王五", "电话": "13800003333", "城市": "广州", "年龄": 28},
    {"姓名": "赵六", "电话": "13800004444", "城市": "北京", "年龄": 22},
]

# 遍历通讯录
print("=== 全部联系人 ===")
for person in contacts:
    print(f"{person['姓名']} - {person['电话']} - {person['城市']}")

# 查找北京的联系人
print()
print("=== 北京的联系人 ===")
for person in contacts:
    if person["城市"] == "北京":
        print(person["姓名"])

# 找出年龄最大的联系人
oldest = contacts[0]
for person in contacts:
    if person["年龄"] > oldest["年龄"]:
        oldest = person
print(f"\n年龄最大：{oldest['姓名']}，{oldest['年龄']}岁")

# ========== 字典嵌套字典：图书管理系统 ==========

library = {
    "B001": {"书名": "Python入门", "作者": "张三", "价格": 59, "库存": 10},
    "B002": {"书名": "Python进阶", "作者": "李四", "价格": 79, "库存": 5},
    "B003": {"书名": "数据结构", "作者": "王五", "价格": 89, "库存": 3},
}

# 查询
book_id = "B002"
if book_id in library:
    book = library[book_id]
    print(f"书名：{book['书名']}")
    print(f"作者：{book['作者']}")
    print(f"价格：{book['价格']}元")
    print(f"库存：{book['库存']}本")

# 统计总库存和总价值
total_stock = 0
total_value = 0
for bid, info in library.items():
    total_stock = total_stock + info["库存"]
    total_value = total_value + info["价格"] * info["库存"]
print(f"\n总库存：{total_stock}本，总价值：{total_value}元")

# ========== 字典的值是列表：学生选课 ==========

courses = {
    "小明": ["Python", "Java", "英语"],
    "小红": ["Python", "数学", "设计"],
    "小刚": ["Java", "英语", "体育"],
}

# 查谁选了Python
print()
print("选了Python的同学：")
for name, course_list in courses.items():
    if "Python" in course_list:
        print(name)

# 统计每门课有多少人选
from collections import Counter
all_courses = []
for course_list in courses.values():
    all_courses.extend(course_list)    # 把所有课合并到一个列表
course_count = {}
for c in all_courses:
    course_count[c] = course_count.get(c, 0) + 1
print("\n选课统计：", course_count)
```

## 📝 本节课核心知识点总结

| 序号 | 知识点 | 一句话记忆 |
|------|--------|------------|
| 1 | 列表套字典 | 最常见模式，每项是一个记录 |
| 2 | 字典套字典 | 通过外层键找到内层字典 |
| 3 | 字典套列表 | 一个键对应多个值 |
| 4 | 嵌套访问 | 一层一层取：`data["键"][索引]["键"]` |
| 5 | `.extend()` | 把一个列表的元素加到另一个列表里 |
| 6 | `.get(k, 0)` | 安全取字典值，没有则返回0 |
