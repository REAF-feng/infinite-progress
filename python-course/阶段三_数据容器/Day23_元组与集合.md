## 📖 知识点讲解

### 1. 元组 Tuple —— 不可修改的列表

元组用**小括号** `()`，一旦创建就不能修改（不能增删改）。

```python
列表 = [1, 2, 3]    # 可以改，用中括号
元组 = (1, 2, 3)    # 不能改，用小括号
```

**什么时候用元组？** 当你确定这组数据不会变化时——比如一周的天数、一年的月份、某个人的出生日期。

### 2. 集合 Set —— 不能重复的容器

集合用**大括号** `{}`，特点：
- 元素不重复（自动去重）
- 无序（没有索引，不能通过位置访问）
- 可以做交集、并集、差集运算

```python
{1, 2, 3, 3, 2}  →  自动变成 {1, 2, 3}
```

### 3. 三种容器对比

| 特性 | 列表 `[]` | 元组 `()` | 集合 `{}` |
|------|-----------|-----------|-----------|
| 可修改 | ✅ | ❌ | ✅（但只能增删不能改） |
| 可重复 | ✅ | ✅ | ❌ 自动去重 |
| 有序 | ✅ | ✅ | ❌ 无序 |
| 有索引 | ✅ | ✅ | ❌ |

## 💻 课堂演示代码

```python
# ========== 元组基本操作 ==========

# 创建元组
point = (3, 5)                   # 坐标点
colors = ("红", "绿", "蓝")       # RGB颜色
single = (42,)                   # 只有一个元素的元组，必须加逗号！
not_tuple = (42)                 # 这不是元组，只是数字42（括号当数学括号了）

print("坐标：", point)
print("x坐标：", point[0])        # 可以访问索引
print("y坐标：", point[1])

# point[0] = 10                   # ❌ 报错！元组不能修改

# 元组拆包（很实用的特性！）
x, y = point                     # 一次性把元组里的值赋给两个变量
print(f"x={x}, y={y}")

# 交换两个变量（Python特有！）
a, b = 10, 20
a, b = b, a                      # 本质是元组拆包
print(f"交换后：a={a}, b={b}")

# ========== 集合基本操作 ==========

# 创建集合
nums = {1, 2, 3, 3, 2, 1, 4}
print("集合自动去重：", nums)      # {1, 2, 3, 4}

# 增删操作
fruits = {"苹果", "香蕉"}
fruits.add("橘子")                # 添加元素
print("添加后：", fruits)

fruits.remove("香蕉")             # 删除元素（不存在会报错）
print("删除后：", fruits)

fruits.discard("西瓜")            # 安全删除（不存在也不报错）

# 集合运算（交、并、差）
set_a = {1, 2, 3, 4, 5}
set_b = {4, 5, 6, 7, 8}

print("交集（共同有的）：", set_a & set_b)       # {4, 5}
print("并集（合在一起去重）：", set_a | set_b)   # {1,2,3,4,5,6,7,8}
print("差集（a有b没有）：", set_a - set_b)       # {1, 2, 3}
print("对称差（只在一边的）：", set_a ^ set_b)   # {1,2,3,6,7,8}

# 集合去重应用
numbers = [1, 2, 2, 3, 3, 3, 4, 4, 4, 4]
unique = list(set(numbers))      # 转成集合去重，再转回列表
print("去重后：", unique)

# 成员检查（集合比列表快很多！）
print(3 in set_a)                 # True
```

## 📝 本节课核心知识点总结

| 序号 | 知识点 | 一句话记忆 |
|------|--------|------------|
| 1 | 元组 `()` | 不可修改的列表，适合存常量 |
| 2 | 单元素元组 | 必须加逗号 `(42,)` |
| 3 | 元组拆包 | `a, b = (1, 2)` 一次赋多个值 |
| 4 | 集合 `{}` | 自动去重、无序、不可索引 |
| 5 | `&` 交集 | 两个集合都有的 |
| 6 | `\|` 并集 | 合在一起去重 |
| 7 | `-` 差集 | 前面有后面没有的 |
