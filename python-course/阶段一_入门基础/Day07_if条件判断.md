## 📖 知识点讲解

### 1. if是什么？——程序里的"红绿灯"

生活中你时刻在做判断：
- **如果** 外面下雨 → 带伞出门
- **否则如果** 阴天 → 带伞以防万一
- **否则** → 不带伞

程序里的if语句就是这个逻辑，让程序根据不同的条件，选择不同的路走。

### 2. if语句的三种写法

**写法一：if 单独使用（最简单）**
```python
if 条件:
    要做的事    # 前面空4格！这是Python的规定
```
条件为True就执行缩进的代码，为False就跳过。

**写法二：if...else（二选一）**
```python
if 条件:
    条件成立做的事
else:
    条件不成立做的事
```
两条路必走一条。

**写法三：if...elif...else（多选一）**
```python
if 条件1:
    情况1做的事
elif 条件2:
    情况2做的事
elif 条件3:
    情况3做的事
else:
    以上都不成立做的事
```
从上往下检查，哪个条件先成立就执行哪个，后面的都不看了。

> ⚠️ **缩进是Python的灵魂！** if下面要执行的代码必须缩进（前面空4格）。不缩进Python不知道哪些代码归if管。同一级的缩进必须对齐，否则报错！

## 💻 课堂演示代码

```python
# ========== 示例1：判断及格 ==========

score = 75
if score >= 60:
    print("恭喜你，及格了！")    # 条件成立，会显示
    print("继续加油！")           # 缩进相同，也是if的一部分
print("成绩查询完毕")              # 没缩进，不管条件成不成立都会执行

# ========== 示例2：if...else 二选一 ==========

age = int(input("请输入你的年龄："))
if age >= 18:
    print("你是成年人，可以进入")     # age>=18时走这条路
else:
    print("你还未成年，不能进入")     # age<18时走这条路

# ========== 示例3：if...elif...else 多选一 ==========

score = int(input("请输入你的考试分数："))

if score >= 90:
    print("优秀！等级A")
elif score >= 80:
    print("良好！等级B")
elif score >= 70:
    print("中等！等级C")
elif score >= 60:
    print("及格！等级D")
else:
    print("不及格，需要补考。等级E")

# ========== 示例4：嵌套if（if里面套if）==========

has_ticket = input("你有票吗？（输入 y 或 n）：") == "y"
age = int(input("你多大？"))

if has_ticket:
    # 有票的情况再看年龄
    if age >= 18:
        print("请进成人区")
    else:
        print("请进儿童区，注意安全")
else:
    print("请先去买票")
```

## 📝 本节课核心知识点总结

| 序号 | 知识点 | 一句话记忆 |
|------|--------|------------|
| 1 | `if` | "如果……就……"，条件成立才执行 |
| 2 | `elif` | "否则如果……"，多一个选择 |
| 3 | `else` | "否则……"，以上都不成立时执行 |
| 4 | 缩进 | if下面要执行的代码必须空4格 |
| 5 | 冒号 | if/elif/else后面必须有英文冒号 `:` |
| 6 | 判断顺序 | 从上往下，谁先成立走谁，后面的不管 |
