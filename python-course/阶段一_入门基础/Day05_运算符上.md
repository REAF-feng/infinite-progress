## 📖 知识点讲解

### 1. 七大算术运算符

把Python想象成一个超级计算器，它不仅能做加减乘除，还有一些特殊的运算：

| 运算符 | 名称 | 例子 | 结果 | 说明 |
|--------|------|------|------|------|
| `+` | 加 | `10 + 3` | `13` | 日常的加法 |
| `-` | 减 | `10 - 3` | `7` | 日常的减法 |
| `*` | 乘 | `10 * 3` | `30` | **注意！乘号是*，不是×** |
| `/` | 除 | `10 / 3` | `3.333...` | 除法的结果永远是小数 |
| `//` | 整除 | `10 // 3` | `3` | 只要商的整数部分，砍掉小数 |
| `%` | 取余 | `10 % 3` | `1` | 除法剩下的余数 |
| `**` | 次方 | `10 ** 3` | `1000` | 即10³，10的3次方 |

### 2. 生活化理解整除和取余

12个苹果，分给5个小朋友：

- **整除 `12 // 5` = 2**：每个小朋友**分到2个**苹果（剩下的不管）
- **取余 `12 % 5` = 2**：全部分完后还**剩下2个**苹果

**取余的实用场景：判断奇偶数**
- 偶数 ÷ 2 的余数 = 0 → `num % 2 == 0` 就是偶数
- 奇数 ÷ 2 的余数 = 1 → `num % 2 == 1` 就是奇数

### 3. 运算优先级（先算谁后算谁）

和小学数学一样：**先乘除，后加减，有括号先算括号里的**。

```python
10 + 3 * 2       → 先算3*2=6，再算10+6=16
(10 + 3) * 2     → 先算10+3=13，再算13*2=26
```

**优先级从高到低：**
1. `()` 括号
2. `**` 次方
3. `* / // %` 乘除整除取余
4. `+ -` 加减

> 💡 **小技巧：不确定优先级时，加括号最保险！**

## 💻 课堂演示代码

```python
# ========== 七大运算符逐个演示 ==========

a = 10
b = 3

print("a =", a, ", b =", b)
print()  # 空行

# 加减乘除
print("加法 a + b =", a + b)          # 10 + 3 = 13
print("减法 a - b =", a - b)          # 10 - 3 = 7
print("乘法 a * b =", a * b)          # 10 × 3 = 30
print("除法 a / b =", a / b)          # 10 ÷ 3 = 3.333...，注意结果是小数

# 三个特殊的
print("整除 a // b =", a // b)        # 商是3，砍掉小数部分 → 3
print("取余 a % b =", a % b)          # 余数是1
print("次方 a ** b =", a ** b)        # 10的3次方 = 1000

# ========== 取余的妙用：判断奇偶数 ==========

num1 = 8
num2 = 7
print(f"{num1}是偶数吗？", num1 % 2 == 0)   # True，8÷2余0，是偶数
print(f"{num2}是奇数吗？", num2 % 2 == 1)   # True，7÷2余1，是奇数

# ========== 运算优先级 ==========

result1 = 10 + 3 * 2       # 先乘后加：3*2=6, 10+6=16
result2 = (10 + 3) * 2     # 有括号先算括号：10+3=13, 13*2=26
print("10 + 3 * 2 =", result1)
print("(10 + 3) * 2 =", result2)

# ========== 综合：简易计算器 ==========

print("===== 四则运算计算器 =====")
num1 = float(input("请输入第一个数字："))
num2 = float(input("请输入第二个数字："))
print()
print(f"{num1} + {num2} = {num1 + num2}")
print(f"{num1} - {num2} = {num1 - num2}")
print(f"{num1} × {num2} = {num1 * num2}")
print(f"{num1} ÷ {num2} = {num1 / num2}")
print(f"{num1} ÷ {num2} 的整数商 = {num1 // num2}")
print(f"{num1} ÷ {num2} 的余数 = {num1 % num2}")
print(f"{num1} 的 {num2} 次方 = {num1 ** num2}")
```
