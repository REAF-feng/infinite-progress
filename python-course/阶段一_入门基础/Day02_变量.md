## 📖 知识点讲解

### 1. 什么是变量？—— 给数据起个名字

想象你的书包有三个口袋：

- 左边口袋放了一支笔
- 中间口袋放了一本语文书
- 右边口袋放了一个橡皮

每次你要找东西时，不用翻遍整个书包，直接说"左边口袋"就能找到笔。

**变量就是给数据贴的"标签纸"**。你把"小明"这个名字存到一个叫 `name` 的变量里，以后想用"小明"的时候，直接用 `name` 就行。

```
变量名 = 值

name = "小明"      →   name这个标签指向了"小明"
age = 18           →   age这个标签指向了18
score = 95.5       →   score这个标签指向了95.5
```

### 2. 赋值语句详解

`=` 在Python里不叫"等于号"，它叫**赋值号**。它的作用是把右边的数据"塞进"左边的变量里。

```
变量名 = 数据
  ↑       ↑
 左边    右边（先算右边，再放进左边）
```

**生活类比：**
- `name = "小明"` 就像给快递盒贴标签，盒子上的标签叫name，盒子里装的是"小明"
- `age = 18` 就像给另一个盒子贴标签age，装的是数字18

### 3. 变量命名规则（必须遵守）

| 规则 | 正确示例 | 错误示例 | 原因 |
|------|----------|----------|------|
| 只能用字母、数字、下划线 | `name_1` | `name-1` | 减号不允许 |
| 不能以数字开头 | `stu1` | `1stu` | 数字开头不行 |
| 不能包含空格 | `my_name` | `my name` | 空格会断开 |
| 区分大小写 | `Name`和`name`是两个不同变量 |
| 不能用Python内置词 | 不能用`print`、`if`等做变量名 |

> 💡 **命名建议：** 用有意义的英文或拼音，比如用 `student_name`（学生姓名），不要用 `a`、`b`、`x` 这种没意义的名字。

## 💻 课堂演示代码

```python
# ========== 基本变量操作 ==========

# 创建变量：把数据"装"进变量里
name = "小明"            # 变量name，存了名字"小明"
age = 18                 # 变量age，存了年龄18
height = 1.75            # 变量height，存了身高1.75（单位：米）
is_student = True        # 变量is_student，存了"是学生"这个判断（True=是，False=否）

# 使用变量：用print把变量里的值显示出来
print(name)              # 输出：小明
print(age)               # 输出：18
print(height)            # 输出：1.75
print(is_student)        # 输出：True

# ========== 变量可以重新赋值（覆盖原来的值） ==========

score = 80               # 一开始成绩是80
print("第一次成绩：", score)   # 输出：第一次成绩：80

score = 95               # 改了！成绩变成95
print("修改后成绩：", score)   # 输出：修改后成绩：95

# ========== 变量之间可以参与运算 ==========

a = 10
b = 20
c = a + b                # c = 10 + 20 = 30
print("a + b =", c)       # 输出：a + b = 30

# ========== 变量和文字混合输出 ==========

student_name = "小红"
student_age = 16
print("我叫", student_name, "，今年", student_age, "岁")
# 输出：我叫 小红 ，今年 16 岁

# ========== 用f-string更优雅地拼接 ==========
# f-string 是 f"..." 的格式，花括号 { } 里的变量会自动替换成它的值
print(f"我叫{student_name}，今年{student_age}岁")
# 输出：我叫小红，今年16岁（注意这个没有多余空格，更好看）
```
