## 📖 知识点讲解

### 1. 为什么数据要分类型？

想象你在填一张表格：
- "年龄"那一栏，你应该填数字（18）
- "姓名"那一栏，你应该填文字（小明）
- "是否已婚"那一栏，你只能填"是"或"否"

你不会在"年龄"栏写"小明"，也不会在"姓名"栏写"18岁"。

**数据有分类，就像便利店商品分区域**——饮料区和零食区不同，你不能拿饮料的价格去算零食的折扣。Python里数据分四种基础类型：

### 2. 四种基本数据类型

```
数据类型大家庭
├── 整数 int      → 就是整数：1, 2, 100, -5, 0
├── 小数 float    → 带小数点的数：3.14, 1.75, -0.5
├── 字符串 str    → 文字内容："你好", "小明", "abc123"
└── 布尔值 bool   → 只有两个值：True（真/是） 和 False（假/否）
```

### 3. 用 type() 查看类型

`type()` 就像是一个"验钞机"——你把数据放进去，它告诉你这个数据是什么类型。

```python
type(18)       → 告诉你这是 int（整数）
type("18")     → 告诉你这是 str（字符串），虽然看起来像数字但实际是文字！
```

### 4. 类型转换——给数据"换马甲"

有时候需要把一种类型变成另一种类型：

```python
int("18")      → 把字符串"18"变成整数18
str(18)        → 把整数18变成字符串"18"
float("3.14")  → 把字符串"3.14"变成小数3.14
```

**为什么需要类型转换？** 因为不同类型不能混着算！

```python
"18" + 5       → ❌ 报错！字符串和数字不能直接加
int("18") + 5  → ✅ 先把字符串变成数字，再算18+5=23
```

> ⚠️ **常见错误：** `int("abc")` 会报错！因为"abc"根本不是数字，没法转。只有纯数字的字符串才能转成数字。

## 💻 课堂演示代码

```python
# ========== 认识四种基本类型 ==========

# 整数 int — 没有小数点的数
age = 18
students = 45
temperature = -5
print(type(age))          # 输出：<class 'int'> （表示这是整数类型）

# 小数 float — 有小数点的数
price = 9.90
height = 1.75
pi = 3.14159
print(type(price))        # 输出：<class 'float'> （表示这是小数类型）

# 字符串 str — 引号里的内容
name = "小明"
school = '第一中学'
address = "北京市朝阳区"
print(type(name))         # 输出：<class 'str'> （表示这是字符串类型）

# 布尔值 bool — 只有True和False两个值
is_adult = True           # 是成年人
has_car = False           # 没有车
print(type(is_adult))     # 输出：<class 'bool'> （表示这是布尔类型）

# ========== 类型转换演示 ==========

# 情况1：字符串数字 → 真数字
num_str = "100"           # 这是字符串"100"，不是数字100
print(type(num_str))      # 输出：<class 'str'>
num_int = int(num_str)    # 把字符串转成整数
print(num_int, type(num_int))  # 输出：100 <class 'int'>

# 情况2：数字 → 字符串
num = 88
num_to_str = str(num)     # 把数字转成字符串
print(num_to_str, type(num_to_str))  # 输出：88 <class 'str'>

# 情况3：整数 ↔ 小数
x = 10
y = float(x)              # 整数转小数
print(y)                  # 输出：10.0  （变成了小数）

z = 3.99
w = int(z)                # 小数转整数，注意会直接砍掉小数部分！
print(w)                  # 输出：3  （不是四舍五入，是直接去掉小数！）

# ========== 类型不匹配会报错 ==========

# 下面的代码会报错，试试去掉#号运行看看报什么错
# result = "我的分数是" + 95   # ❌ 字符串+数字会报错
result = "我的分数是" + str(95)  # ✅ 把数字转成字符串再拼接
print(result)               # 输出：我的分数是95

# ========== 用input接收用户输入（预习明天的内容）==========
# input()收到的内容永远是字符串类型！
user_input = input("请输入一个数字：")  # 假设用户输入了 42
print("你输入的是：", user_input)
print("它的类型是：", type(user_input))  # 你会发现是 str 类型，不是 int！
```

## 📝 本节课核心知识点总结

| 序号 | 知识点 | 一句话记忆 |
|------|--------|------------|
| 1 | `int`（整数） | 没有小数点的数，如 1, 100, -5 |
| 2 | `float`（小数） | 带小数点的数，如 3.14, -0.5 |
| 3 | `str`（字符串） | 引号里的文字，"你好"、"abc" |
| 4 | `bool`（布尔值） | 只有 `True`（是）和 `False`（否） |
| 5 | `type()` | 查看数据是什么类型 |
| 6 | `int()` `str()` `float()` | 类型转换三兄弟 |
| 7 | 类型不匹配 | 字符串和数字不能直接加，需要先转换 |
