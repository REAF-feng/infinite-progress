## 📖 知识点讲解

### 1. 循环是什么？

生活中你经常重复做事：
- 考试时"一道一道题往下做，直到做完全部"
- 吃饭时"一口一口吃，直到吃完"
- 跑步时"一圈一圈跑，直到跑完10圈"

程序中的**循环**就是让一段代码重复执行，直到某个条件不再满足。

### 2. while循环的结构

```python
while 条件:
    重复做的事    # 前面空4格！
```

**执行流程：**
```
① 检查条件是否为True
② 如果是True → 执行缩进里的代码 → 回到①
③ 如果是False → 跳过循环，继续往下走
```

**生活类比：** 就像"只要还没到站，就继续坐车"，每一站检查一次"到了没"。

### 3. 循环的三个关键要素

| 要素 | 说明 | 例子 |
|------|------|------|
| 初始值 | 循环开始前的变量 | `count = 1` |
| 循环条件 | 什么时候继续循环 | `count <= 5` |
| 变化量 | 每轮怎么变（避免死循环） | `count = count + 1` |

> ⚠️ **死循环警告！** 如果条件永远为True，程序就停不下来了！
> ```python
> count = 1
> while count <= 5:
>     print(count)
>     # 忘了写 count = count + 1  ← 条件永远成立，程序卡死！
> ```
> 如果程序卡死，按 `Ctrl + C` 可以强制停止。

## 💻 课堂演示代码

```python
# ========== 示例1：从1数到5 ==========

count = 1                    # ① 初始值：从1开始数
while count <= 5:            # ② 条件：还没数到5就继续
    print(f"第{count}次")    #    做的事：显示当前数字
    count = count + 1        # ③ 变化：数字+1，准备下一轮
print("数完了！")

# 输出：
# 第1次
# 第2次
# 第3次
# 第4次
# 第5次
# 数完了！

# ========== 示例2：累加求和 1+2+3+...+100 ==========

total = 0                    # 总和，从0开始累加
num = 1                      # 从1开始
while num <= 100:
    total = total + num      # 把num加到总和里
    num = num + 1            # num增加1
print("1加到100的和是：", total)  # 输出：5050

# ========== 示例3：让用户反复猜数字 ==========

secret = 7                   # 谜底
guess = int(input("猜一个1~10的数字："))

while guess != secret:       # 只要猜不对就继续
    if guess > secret:
        print("猜大了，再试试")
    else:
        print("猜小了，再试试")
    guess = int(input("再猜一次："))

print("恭喜你，猜对了！")

# ========== 示例4：用break提前结束循环 ==========

# 不断让用户输入，输入q就退出
while True:                  # True永远为真，理论上会无限循环
    user_input = input("请输入内容（输入q退出）：")
    if user_input == "q":
        print("退出程序")
        break                # break直接跳出循环！
    print(f"你输入的是：{user_input}")
```

## 📝 本节课核心知识点总结

| 序号 | 知识点 | 一句话记忆 |
|------|--------|------------|
| 1 | `while`循环 | "条件成立就一直做"，条件不成立才停 |
| 2 | 循环三要素 | 初始值 + 循环条件 + 变化量，缺一不可 |
| 3 | 死循环 | 条件永远True，程序停不下来，按Ctrl+C强制停 |
| 4 | `break` | 直接跳出循环，后面不执行了 |
| 5 | `count += 1` | 等价于 `count = count + 1`，更简洁的写法 |
