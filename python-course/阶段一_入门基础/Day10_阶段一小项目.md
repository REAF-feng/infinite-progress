## 📖 项目需求说明

我们要做一个**多功能计算器**，功能包括：
1. 加法运算
2. 减法运算
3. 乘法运算
4. 除法运算（要处理除数为0的情况！）
5. 判断一个数是奇数还是偶数
6. 计算一个数的平方和立方

程序运行后显示一个菜单让用户选择功能，然后根据选择执行对应计算。

---

## 🧠 设计思路（写代码前先想清楚）

```
第一步：显示一个菜单，告诉用户有哪些功能可选
第二步：让用户输入数字选择功能
第三步：根据用户的选择，执行对应的计算
第四步：显示结果
第五步：问用户要不要继续，继续的话回到第一步
```

---

## 💻 完整代码

```python
# =========================================
# 多功能计算器 —— 阶段一综合项目
# 知识点：print, 变量, 数据类型, input,
#         运算符, if判断, while循环
# =========================================

print("=" * 40)
print("        欢迎使用多功能计算器！")
print("=" * 40)

# 用while循环让程序可以反复使用
while True:
    # ---- 第一步：显示功能菜单 ----
    print()
    print("请选择功能（输入数字1~6）：")
    print("  1. 加法")
    print("  2. 减法")
    print("  3. 乘法")
    print("  4. 除法")
    print("  5. 奇偶数判断")
    print("  6. 平方立方计算")
    print("  0. 退出程序")
    print()

    # ---- 第二步：获取用户选择 ----
    choice = input("请输入你的选择（0~6）：")

    # ---- 第三步：根据选择执行功能 ----

    if choice == "0":
        # 用户选择退出
        print("谢谢使用，再见！")
        break    # 跳出while循环，程序结束

    elif choice == "1":
        # 加法
        print("--- 加法运算 ---")
        a = float(input("请输入第一个数："))
        b = float(input("请输入第二个数："))
        result = a + b
        print(f"结果：{a} + {b} = {result}")

    elif choice == "2":
        # 减法
        print("--- 减法运算 ---")
        a = float(input("请输入第一个数："))
        b = float(input("请输入第二个数："))
        result = a - b
        print(f"结果：{a} - {b} = {result}")

    elif choice == "3":
        # 乘法
        print("--- 乘法运算 ---")
        a = float(input("请输入第一个数："))
        b = float(input("请输入第二个数："))
        result = a * b
        print(f"结果：{a} × {b} = {result}")

    elif choice == "4":
        # 除法（特别注意：除数不能为0！）
        print("--- 除法运算 ---")
        a = float(input("请输入被除数："))
        b = float(input("请输入除数："))

        if b == 0:
            print("⚠️ 错误！除数不能为0，请重新选择。")
        else:
            result = a / b
            print(f"结果：{a} ÷ {b} = {result}")

    elif choice == "5":
        # 奇偶数判断
        print("--- 奇偶数判断 ---")
        num = int(input("请输入一个整数："))
        if num % 2 == 0:
            print(f"{num} 是偶数")
        else:
            print(f"{num} 是奇数")

    elif choice == "6":
        # 平方立方计算
        print("--- 平方立方计算 ---")
        num = float(input("请输入一个数字："))
        square = num ** 2     # 平方 = 数的2次方
        cube = num ** 3       # 立方 = 数的3次方
        print(f"{num} 的平方是：{square}")
        print(f"{num} 的立方是：{cube}")

    else:
        # 输入的不是0~6之间的数字
        print("⚠️ 输入有误！请输入0~6之间的数字。")

    # ---- 分隔线，让下一轮看得清楚 ----
    print("-" * 40)

# 程序到此结束（用户选0时break跳到这里）
print("程序已退出。")
```

---

## 📝 代码知识点拆解

| 代码段落 | 用到的知识点 |
|----------|-------------|
| `print("=" * 40)` | 字符串乘法，`"=" * 40` 产生40个等号 |
| `while True:` | 无限循环，让程序反复运行 |
| `choice = input(...)` | 接收用户输入 |
| `if choice == "0":` | 字符串比较，注意是 `"0"` 不是 `0` |
| `break` | 跳出while循环 |
| `elif choice == "4":` | 多分支判断 |
| `if b == 0:` | 嵌套if，处理特殊情况 |
| `num % 2 == 0` | 取余判断奇偶数 |
| `num ** 2` | 次方运算 |
| `f"结果：{a} + {b} = {result}"` | f-string格式化输出 |

## 🛠️ 优化思考（⭐拓展，选做）

当前代码有一个明显的问题：**加法、减法、乘法三个功能里，获取输入数字的代码是重复的**。到阶段四学了函数之后，我们可以把这些重复代码提取成一个函数，让代码更简洁。

现在的代码虽然有点重复，但作为第一个完整项目，**清晰易懂比简洁更重要**。
