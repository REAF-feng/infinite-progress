## 📖 知识点讲解

### 1. Python是什么？

把你和电脑想象成两个说不同语言的人。你说中文，电脑只懂"机器语言"（一串010101的数字）。你俩没法直接交流。

**Python就是一个"翻译官"**。你用Python规定的简单"语法"写指令，Python帮你翻译成电脑能懂的机器语言。这样你不用学010101，也能让电脑帮你做事。

```
你（人类）  →  写Python代码  →  Python（翻译官）  →  电脑执行
  "print('你好')"             翻译成机器语言           显示"你好"
```

### 2. print()是什么？

`print()` 是Python里最基础的一个**命令**，它的作用就是：**把内容显示在屏幕上**。

你可以把它想象成一个"大喇叭"📢——你往括号里放什么，它就帮你喊出来什么。

**生活中的类比：**
- 你写小纸条："今晚吃什么" → 把纸条放进 print() 这个喇叭 → 屏幕显示：今晚吃什么
- 你写：`print("你好")` → Python执行 → 屏幕输出：你好

### 3. 什么是字符串？

在上面 `print("你好")` 中，`"你好"` 就是**字符串**。字符串就是**一段文字内容**，必须用英文的双引号 `" "` 或单引号 `' '` 括起来。

```
✅ 正确：print("你好")      用英文双引号
✅ 正确：print('你好')      用英文单引号
❌ 错误：print("你好")      用中文引号，程序不认识！
❌ 错误：print(你好)        没加引号，程序以为"你好"是个变量名
```

> ⚠️ **请注意！** 写代码时，键盘输入法必须切换到**英文状态**！所有括号、引号、逗号都要用英文符号。这是新手最容易犯的错！

## 💻 课堂演示代码

打开VS Code，新建文件命名为 `day01.py`，逐行输入以下代码：

```python
# 这一行是"注释"，前面有#号的行不会被Python执行
# 注释是用来给代码写说明的，方便自己和别人看懂

print("Hello World!")          # 显示英文：Hello World!
print("你好，世界！")            # 显示中文：你好，世界！
print('用单引号也可以')          # 单引号效果和双引号一样
print(123)                      # 数字可以不加引号，也能显示
print(10 + 20)                  # 会先算10+20=30，然后显示30
print("10 + 20")                # 加了引号就是文字，直接显示"10 + 20"，不会算
print("我叫小明，今年18岁")       # 一句话完整显示
print("学Python，")             # 注意：print每执行完一次会自动换行
print("从今天开始！")
```

**运行结果：**
```
Hello World!
你好，世界！
用单引号也可以
123
30
10 + 20
我叫小明，今年18岁
学Python，
从今天开始！
```

**逐行解释：**

| 代码 | 解释 |
|------|------|
| `# 这是注释` | `#` 开头的一行不会被运行，只是给你看的说明文字 |
| `print("Hello World!")` | 把双引号内的文字原样显示出来 |
| `print('用单引号也可以')` | 单引号和双引号作用一样，但要配对使用 |
| `print(123)` | 数字可以不加引号，直接显示 |
| `print(10 + 20)` | 不加引号时，Python会先**计算**再显示结果 |
| `print("10 + 20")` | 加引号时，Python把它当**文字**，不算结果 |

### ⭐ 拓展：print() 的小技巧

```python
# 技巧1：用逗号连接多个内容，中间会自动加空格
print("我叫", "小明", "今年", 18, "岁")
# 输出：我叫 小明 今年 18 岁

# 技巧2：print()里什么都不写，就输出一个空行
print("第一行")
print()             # 空行
print("第三行")

# 技巧3：end参数可以让print不换行（了解即可，后面会细讲）
print("好朋友", end="")
print("一辈子")
# 输出：好朋友一辈子（连在一起了）
```
