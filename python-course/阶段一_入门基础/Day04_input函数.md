## 📖 知识点讲解

### 1. input() 是什么？

之前我们写的程序都是"自说自话"——程序显示什么，你只能看什么。`input()` 不一样，它能让程序**停下来等你打字**，等你按了回车后，程序把你打的内容拿过来用。

**生活类比：** input() 就像服务员问你"您要点什么？"，然后等你回答。服务员把你说的菜名记下来，传给厨房。

```
程序运行到 input() → 停下来等 → 你输入内容 + 回车 → 程序拿到你的输入继续跑
```

### 2. input() 基本用法

```python
变量 = input("提示文字")
```

- `"提示文字"`：显示给用户看的提示，告诉用户该输入什么
- 用户输入的内容会被存到左边的变量里
- **重要：input() 拿到的永远是字符串类型！**

### 3. 输入数字要注意什么？

因为 `input()` 返回的永远是字符串，如果想让用户输入数字做计算，必须先用 `int()` 或 `float()` 转换！

```python
age = input("请输入你的年龄：")  # 用户输入18，但age存的是字符串"18"
# age = age + 1                  # ❌ 会报错！字符串不能+1
age = int(age) + 1               # ✅ 先转成整数，再加1
```

## 💻 课堂演示代码

```python
# ========== 基础：接收输入并显示 ==========

# 让用户输入名字，然后打招呼
name = input("请输入你的名字：")        # 程序停在这里等你输入
print("你好，", name, "！欢迎学习Python！")  # 把你输入的名字显示出来

# ========== 接收数字输入 ==========

# 注意：input拿到的都是字符串，要转成数字才能做计算！
age_str = input("请输入你的年龄：")     # 拿到的"18"是字符串
age = int(age_str)                     # 转成整数
print("你明年就", age + 1, "岁了")      # 可以做计算了

# 简化写法：一步到位
height = float(input("请输入你的身高（米）："))  # 输入→转小数，一步完成
print("你的身高是", height, "米")

# ========== 完整对话小程序 ==========

print("========== 欢迎来到自我介绍程序 ==========")
name = input("Q1: 你叫什么名字？")
age = int(input("Q2: 你今年几岁？"))
city = input("Q3: 你住在哪个城市？")
hobby = input("Q4: 你的爱好是什么？")
print()  # 空一行
print("========== 你的自我介绍卡 ==========")
print(f"姓名：{name}")
print(f"年龄：{age}岁")
print(f"城市：{city}")
print(f"爱好：{hobby}")
print(f"十年后你{age + 10}岁")      # 直接做计算
print("===================================")

# ========== 简单计算器 ==========

print("===== 加法计算器 =====")
num1 = int(input("请输入第一个数字："))
num2 = int(input("请输入第二个数字："))
result = num1 + num2
print(f"{num1} + {num2} = {result}")
```
