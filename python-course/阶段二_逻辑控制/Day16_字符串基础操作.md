## 📖 知识点讲解

### 1. 字符串的本质

字符串就是一串按顺序排列的字符。Python给每个字符编号（从0开始），你可以通过编号找到对应的字符。

```
字符串:  H  e  l  l  o
编号:   0  1  2  3  4  （从左往右数，从0开始）
反向:  -5 -4 -3 -2 -1  （从右往左数，从-1开始）
```

### 2. 索引（取单个字符）

```python
text = "Python"
text[0]    → "P"     第一个字符
text[1]    → "y"     第二个字符
text[-1]   → "n"     倒数第一个字符
```

### 3. 切片（取一段字符）

```python
text[0:3]     → "Pyt"     取编号0,1,2（不包括3！）
text[2:5]     → "tho"     取编号2,3,4
text[:3]      → "Pyt"     从开头取到编号2
text[3:]      → "hon"     从编号3取到结尾
```

**切片规则：** `[开始位置 : 结束位置 : 步长]`，**包前不包后**（和range一样！）

## 💻 课堂演示代码

```python
# ========== 字符串基本操作 ==========

s = "Hello World"
print("原字符串：", s)
print("长度（字符个数）：", len(s))         # 11
print("第一个字符：", s[0])                # H
print("最后一个字符：", s[-1])             # d
print("前5个字符：", s[0:5])               # Hello
print("全部大写：", s.upper())             # HELLO WORLD
print("全部小写：", s.lower())             # hello world

# ========== 字符串拼接和重复 ==========

name = "小明"
greeting = "你好，"
full = greeting + name + "！"             # 用+拼接
print(full)                                # 你好，小明！

line = "-" * 30                            # 重复30次
print(line)

# ========== 常用字符串方法 ==========

text = "  Python 编程  "

print("去掉两边空格：", text.strip())       # "Python 编程"
print("替换：", text.replace("Python", "Java"))  
print("查找位置：", text.find("thon"))      # 返回位置编号
print("统计出现次数：", text.count("o"))    # 统计o出现几次
print("是否全是数字：", "123".isdigit())    # True
print("是否全是字母：", "abc".isalpha())    # True
print("以什么开头：", text.startswith("  P"))  # True
print("以什么结尾：", text.endswith("g"))

# ========== 字符串不可修改 ==========

word = "hello"
# word[0] = "H"    # ❌ 会报错！字符串的单个字符不能修改
# 正确做法：创建新字符串
new_word = "H" + word[1:]    # 首字母改成大写
print(new_word)              # Hello

# ========== 遍历字符串 ==========

name = "Alice"
for ch in name:               # 逐个字符遍历
    print(ch, end="-")        # 输出：A-l-i-c-e-
```
