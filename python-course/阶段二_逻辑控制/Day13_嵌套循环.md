## 📖 知识点讲解

### 1. 什么是嵌套循环？

**生活场景：** 每天的时间安排
- 外层循环：周一、周二、周三……（一周7天）
- 内层循环：第1节课、第2节课……（每天6节课）

你每天要上6节课，一周5天，总共30节课。程序就是：
```python
for 天 in 一周:
    for 节 in 一天的课:
        上课()
```

### 2. 嵌套循环怎么执行？

**关键规则：外层循环每执行1次，内层循环要完整地执行一轮！**

```
外层第1次 → 内层第1次, 内层第2次, ..., 内层最后1次
外层第2次 → 内层第1次, 内层第2次, ..., 内层最后1次
...
外层最后1次 → 内层第1次, 内层第2次, ..., 内层最后1次
```

## 💻 课堂演示代码

```python
# ========== 理解嵌套循环的执行顺序 ==========

print("=== 嵌套循环执行过程 ===")
for i in range(1, 4):           # 外层：i = 1, 2, 3
    for j in range(1, 4):       # 内层：j = 1, 2, 3
        print(f"i={i}, j={j}")
    print("--- 内层结束 ---")

# 输出分析：
# i=1, j=1  ← 外层第1次，内层第1次
# i=1, j=2  ← 外层第1次，内层第2次
# i=1, j=3  ← 外层第1次，内层第3次（内层结束）
# i=2, j=1  ← 外层第2次，内层重新从1开始
# ...

# ========== 图形1：打印正方形 ==========

print()
print("=== 5×5星号正方形 ===")
for row in range(5):            # 行：0到4，共5行
    for col in range(5):        # 列：每行打5个星号
        print("*", end=" ")     # end=" " 表示不换行，加空格
    print()                     # 一行打完，换行

# ========== 图形2：打印直角三角形 ==========

print()
print("=== 直角三角形 ===")
for row in range(1, 6):         # 第1行打1个，第2行打2个……
    for col in range(row):      # 关键！内层循环次数 = 行号
        print("*", end=" ")
    print()

# ========== 经典：完整九九乘法表 ==========

print()
print("=== 九九乘法表 ===")
for i in range(1, 10):          # i 是行（被乘数）
    for j in range(1, i + 1):   # j 是列（乘数），每行列数 = 行号
        print(f"{j}×{i}={i*j:2d}", end="  ")
    print()                     # 换行

# ========== 嵌套while ==========

print()
print("=== 坐标网格 ===")
x = 1
while x <= 3:
    y = 1
    while y <= 3:
        print(f"({x},{y})", end=" ")
        y = y + 1
    print()
    x = x + 1
```

## 📝 本节课核心知识点总结

| 序号 | 知识点 | 一句话记忆 |
|------|--------|------------|
| 1 | 嵌套循环 | 循环里面写循环，外层1次=内层1整轮 |
| 2 | 九九乘法表 | `for i in range(1,10): for j in range(1,i+1):` |
| 3 | 图形打印 | 外层管行数，内层管每行打几个 |
| 4 | `end=" "` | print不换行，用空格分隔 |
| 5 | 嵌套变量名 | 外层用i，内层用j，不要重名 |
