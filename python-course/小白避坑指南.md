## 一、常见报错及解决方法

编程中遇到红色报错文字是再正常不过的事。**报错不是敌人，是帮你找问题的朋友。** 关键是要学会看懂它在说什么。

### 报错1：SyntaxError（语法错误）

**错误信息：** `SyntaxError: invalid syntax`

**常见原因：**
- 用了中文符号（括号、引号、冒号）
- if/while/for/def 后面忘了写冒号 `:`
- 括号没配对（开了3个只关了2个）

**解决办法：** 检查报错指出的那一行，逐字确认符号都是英文状态。

```
❌ if x > 5   （忘了写冒号）
✅ if x > 5:
```

---

### 报错2：IndentationError（缩进错误）

**错误信息：** `IndentationError: expected an indented block`

**常见原因：**
- if/while/for/def 下面该缩进的代码没有缩进
- 缩进混用了空格和Tab键
- 同一级代码缩进不一致

**解决办法：** 统一用**4个空格**缩进。在VS Code中按Tab会自动转成4个空格。

```
❌ if x > 5:
print(x)         # 缺少缩进

✅ if x > 5:
    print(x)     # 前面有4个空格
```

---

### 报错3：NameError（名字错误）

**错误信息：** `NameError: name 'xxx' is not defined`

**常见原因：**
- 变量还没定义就使用了
- 变量名拼写错误（大小写也算！`name` ≠ `Name`）
- 忘记给变量赋值

**解决办法：** 在使用变量前先定义它；检查拼写。

```
❌ print(age)      # age还没定义！
✅ age = 18
   print(age)
```

---

### 报错4：TypeError（类型错误）

**错误信息：** `TypeError: can only concatenate str (not "int") to str`

**常见原因：** 把不同类型的数据混在一起操作，最常见的是字符串+数字。

```
❌ "年龄：" + 18          # 字符串和数字不能直接加
✅ "年龄：" + str(18)     # 把数字转成字符串
✅ f"年龄：{18}"          # 用f-string最方便
```

---

### 报错5：ValueError（值错误）

**错误信息：** `ValueError: invalid literal for int() with base 10: 'abc'`

**常见原因：** 试图把非数字的字符串转成数字。

```
❌ int("abc")     # "abc"不是数字，转不了
✅ 用 try...except 保护输入转换
```

---

### 报错6：IndexError（索引错误）

**错误信息：** `IndexError: list index out of range`

**常见原因：** 访问列表时索引超出了范围。列表有3个元素，你访问了第4个。

```
❌ nums = [1, 2, 3]; nums[3]   # 索引0,1,2，没有3
✅ nums[2]  或 nums[-1]        # 正确的范围
```

---

### 报错7：KeyError（键错误）

**错误信息：** `KeyError: 'xxx'`

**常见原因：** 访问字典中不存在的键。

```
❌ student = {"name": "小明"}; student["age"]   # age不存在
✅ student.get("age", "未知")                   # 安全取值
```

## 二、环境问题修复

### 问题1：VS Code运行Python没反应

**解决方案：**
1. 确认安装了Python扩展（微软官方那个）
2. 按 `Ctrl+Shift+P`，输入 "Python: Select Interpreter"，选择一个Python版本
3. 确认文件后缀是 `.py`
4. 确认文件已保存（Ctrl+S）

### 问题2：终端提示 "'python' 不是内部或外部命令"

**解决方案：** 说明安装Python时没勾选"Add Python to PATH"。
1. 重新运行Python安装程序
2. 在安装界面**一定勾选**底部的"Add Python to PATH"复选框
3. 点击"Install Now"完成安装
4. 重新打开一个cmd窗口，输入 `python --version` 验证

### 问题3：中文显示乱码

**解决方案：** 在文件最顶部加一行：
```python
# -*- coding: utf-8 -*-
```
或者在VS Code右下角点击编码（如UTF-8），选择"通过编码重新打开"→ 选UTF-8。

### 问题4：pip安装库时报错

**常见情况：**
- `pip` 不是内部命令 → 重新安装Python并勾选PATH
- 网络连接超时 → 换国内镜像源：`pip install 库名 -i https://pypi.tuna.tsinghua.edu.cn/simple`
- 权限不足 → 加 `--user`：`pip install --user 库名`

## 三、编程习惯建议

### ✅ DO（应该做的）

1. **手打代码，不复制粘贴** —— 初期每一行都要自己敲，肌肉记忆很重要
2. **写注释** —— 用 `#` 给复杂代码写说明，一周后你就知道为什么了
3. **小步快跑** —— 写3-5行就运行测试，不要写100行再运行
4. **变量名有意义** —— `student_age` 比 `sa` 好一万倍
5. **用Ctrl+S常保存** —— 改代码前先保存，运行前一定要保存
6. **遇到报错先读最后一行** —— 那是错误的直接原因

### ❌ DON'T（不要做的）

1. **不要追求一次写对** —— 老程序员也是写一点测一点
2. **不要死磕一个问题超过30分钟** —— 起来走走、喝杯水，或者第二天再看
3. **不要跳过基础** —— print、变量、if这些看似简单的东西是所有复杂程序的基石
4. **不要在疲劳时学习** —— 编程是脑力活，累了就休息
5. **不要和别人比速度** —— 每个人的学习节奏不同，走稳比走快重要

## 四、拖延症应对策略

### 策略1：5分钟起步法
告诉自己"我只学5分钟"。一旦开始了，你往往会继续下去。最难的不是学1小时，而是坐下来开始。

### 策略2：固定时间法
每天固定一个时间学Python，比如每晚8:00-9:30。形成习惯后，到时身体会自动进入学习状态。

### 策略3：最小可完成目标
不要设"今天学会循环"这种模糊目标。改成"今天把Day08的3个代码例子手打一遍"，清晰、可行、能完成。

### 策略4：打卡问责
把[每日打卡模板](每日打卡模板.md)打印出来贴在墙上。每完成一天打一个勾，连续7天不中断奖励自己一杯奶茶。

### 策略5：找学习搭子
找一个也在学编程的朋友，互相监督。或者在社交媒体上公开你的学习进度。

### 策略6：接受"学不会"的感觉
学习编程时，**有"学不会"的感觉是完全正常的**。这不是你笨，而是大脑在建立新的神经连接。今天觉得难的东西，睡一觉后明天往往就懂了。

## 五、阶段性学习建议

| 阶段 | 如果遇到困难 | 具体行动 |
|------|-------------|----------|
| Day 1-5 | 觉得不习惯 | 反复手打5遍代码，直到能默写print和变量 |
| Day 6-10 | if和循环绕 | 用纸笔画流程图，把条件判断画出来 |
| Day 11-15 | 逻辑变复杂 | 降低难度，只写1层循环，多打印中间结果 |
| Day 16-20 | 项目写不出来 | 先把例子代码改几个数字运行，再慢慢改逻辑 |
| Day 21-25 | 列表字典混淆 | 做一张对比表格，每天看一遍 |
| Day 26-30 | 数据太多记不住 | 用笔记软件整理，重点记"什么时候用" |
| Day 31-35 | 函数不理解 | 把之前写的代码改造成函数，感受"复用"的好处 |
| Day 36-40 | 项目太复杂 | 从空文件开始，一次只添加一个功能，加完测试 |
