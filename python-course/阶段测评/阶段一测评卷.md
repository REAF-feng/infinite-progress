## 四、编程实操题（共40分）

### 题1：成绩等级判断器（15分）

写一个程序，让用户输入分数（0-100），输出对应等级：
- 90~100：优秀
- 80~89：良好
- 70~79：中等
- 60~69：及格
- 0~59：不及格
- 其他：输入无效

### 题2：猜数字游戏（25分）

电脑随机生成1~50的数字，用户有5次机会猜。每次猜完提示"大了"或"小了"。5次内猜对显示"恭喜"，用完机会显示正确答案。

**要求：**
- 使用 `random` 模块
- 使用 `while` 或 `for` 循环
- 有输入验证（非数字提示重新输入）
