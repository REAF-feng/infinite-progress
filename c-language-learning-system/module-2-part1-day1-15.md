---

### 📖 通俗化知识点讲解

#### 1. 程序是什么？
> **生活类比**：程序就像一份"菜谱"。菜谱告诉厨师：第一步洗菜、第二步切菜、第三步下锅炒。程序告诉电脑：第一步读取数据、第二步计算、第三步输出结果。
>
> C语言的 `.c` 文件就是你写给电脑的菜谱，编译器（gcc）把菜谱翻译成电脑能直接执行的"机器语言"。

#### 2. Hello World 程序逐行拆解

```c
#include <stdio.h>   // ① 预处理指令：告诉编译器"我要用标准输入输出库里的功能"
                      //    类比：做菜前先把锅碗瓢盆拿出来准备好

int main() {          // ② 主函数：程序的"入口"，程序从这里开始执行
                      //    每个C程序必须有且只有一个main函数

    printf("Hello, World!\n");  // ③ 调用printf函数：在屏幕上打印文字
                                 //    \n 是换行符，相当于按一下回车键

    return 0;          // ④ 返回值：告诉操作系统"程序正常结束了"
                       //    return 0 = 一切正常，return 1 = 出错了
}                      // ⑤ 右大括号：main函数的结束
```

#### 3. 每个部分的通俗理解

| 代码元素 | 通俗理解 | 必须记住 |
|----------|----------|----------|
| `#include <stdio.h>` | 把"输入输出工具箱"拿过来 | **每个C程序开头都要写** |
| `int main()` | 程序开始执行的"大门" | 必须写，且只能有一个 |
| `{ }` | 大门里面的"房间"，代码写在里面 | 左括号开头，右括号结尾，成对出现 |
| `printf("...");` | 往屏幕上"打印"文字 | 双引号里是要显示的文字 |
| `\n` | "按一下回车换行" | 反斜杠n，不是正斜杠 |
| `return 0;` | "我完成了，一切顺利" | main函数末尾要有 |
| `;` 分号 | 句号，表示一句话说完了 | **C语言几乎所有语句后面都要加分号** |

### 🎯 今日学习目标

---

### 📖 通俗化知识点讲解

#### 1. 变量是什么？

> **生活类比**：变量就像**超市的储物柜**。
> - 每个储物柜有一个**编号**（变量名），比如"A区3号柜"
> - 柜子里可以**存放东西**（数据），比如一个背包、一袋水果
> - 柜子的大小决定了能放什么类型的物品（数据类型），小柜子放不下大行李箱
> - 你可以**随时打开柜子查看或更换**里面的东西

```
变量 = 给内存中的一块空间起了个名字
int score = 90;
 ^^^   ^^^   ^^
  |     |     └── 放在柜子里的东西（值）
  |     └─────── 柜子的编号（变量名）
  └───────────── 柜子类型（整数类型）
```

#### 2. C语言的四种基本数据类型

```c
int age = 18;           // int：整数类型
                        // 类比：只能放整盒的牛奶（整数盒），不能放半盒
                        // 范围：约 -21亿 ~ +21亿
                        // 占用：4个字节（32位）

float price = 9.99;     // float：单精度浮点数（小数）
                        // 类比：可以散装称重，精度到小数点后6-7位
                        // 占用：4个字节

double pi = 3.14159265358979;  // double：双精度浮点数
                                // 类比：更高精度的电子秤，精度到小数点后15位
                                // 占用：8个字节

char grade = 'A';       // char：字符类型
                        // 类比：只存一个字母/符号，像姓名牌上写一个字母
                        // 注意：字符用单引号 ''，不是双引号 ""
                        // 占用：1个字节
```

| 数据类型 | 关键字 | 存什么 | 例子 | 占用空间 |
|----------|--------|--------|------|----------|
| 整数 | `int` | 整数（没有小数点） | 18, -5, 0, 2026 | 4字节 |
| 单精度小数 | `float` | 小数（精度较低） | 3.14, -0.5, 99.9 | 4字节 |
| 双精度小数 | `double` | 小数（精度较高） | 3.14159265358979 | 8字节 |
| 字符 | `char` | 单个字符 | 'A', '9', '+', '\n' | 1字节 |

### 💻 上机敲代码

#### 练习1：变量声明与赋值

```c
/*
 * 文件名：variable_demo.c
 * 功能：认识C语言的变量
 */

#include <stdio.h>

int main()
{
    // 方法1：先声明，后赋值（两步走）
    int age;            // 声明一个整数变量，取名age（年龄）
    age = 18;           // 给age赋值18
    printf("年龄：%d\n", age);   // %d 是整数的"占位符"

    // 方法2：声明的同时赋值（一步到位，更常用）
    float height = 175.5;         // 声明浮点变量并赋值
    printf("身高：%.1f 厘米\n", height);  // %.1f 表示保留1位小数

    double pi = 3.14159265358979; // 双精度浮点数
    printf("圆周率：%.14f\n", pi);  // %.14f 表示保留14位小数

    char grade = 'A';             // 字符变量，注意用单引号
    printf("等级：%c\n", grade);  // %c 是字符的占位符

    // 变量可以重新赋值（这就是为什么叫"变"量）
    age = 19;                     // age从18变成19
    printf("一年后的年龄：%d\n", age);

    return 0;
}
```

**printf 占位符速记**：

| 占位符 | 对应类型 | 记忆方法 |
|--------|----------|----------|
| `%d` | int 整数 | **d**ecimal（十进制整数） |
| `%f` | float/double 小数 | **f**loat（浮点数） |
| `%c` | char 字符 | **c**har（字符） |
| `%s` | 字符串（后面学） | **s**tring（字符串） |

## Day 3：变量与数据类型（下）—— 命名规则、常量、类型转换

### 🎯 今日学习目标
学完后你能：
- 正确命名变量，不踩命名规则的坑
- 区分变量与常量的使用场景
- 理解整数除法和类型转换的陷阱

---

### 📖 通俗化知识点讲解

#### 1. 变量命名规则

> **生活类比**：给宠物起名字。
> - ✅ 可以叫"小白"、"旺财"（有意义）
> - ❌ 不能叫"1号狗"（数字开头违法）
> - ❌ 不能叫"狗$"（特殊字符不行）
> - ❌ 不能和C语言的关键字重名，比如叫"int"（那是C语言自己的词）

**合法命名规则**：
```c
int age;        // ✅ 小写字母
int Age;        // ✅ 大写字母（但和age是不同的变量，区分大小写！）
int studentAge; // ✅ 驼峰命名法（推荐！多个单词第二个起首字母大写）
int student_age; // ✅ 下划线命名法（也推荐，Linux风格）
int _count;     // ✅ 下划线开头（合法但不推荐用于普通变量）
int age2;       // ✅ 包含数字（但不能在开头）

// 错误示例（如果写这些，编译器会报错）：
int 2age;       // ❌ 不能以数字开头
int student-age; // ❌ 不能用减号（会被当成减法运算）
int float;      // ❌ float是C语言关键字，不能用作变量名
int my name;    // ❌ 不能有空格
```

**变量命名好习惯**：
- 名字**有意义**：`s` → ❌ / `studentScore` → ✅（一看就知道是学生成绩）
- 用英文命名变量，提升编程专业度
- 推荐风格：`studentScore`（驼峰）或 `student_score`（下划线），两种选一种坚持

#### 2. 常量

> **生活类比**：圆周率 π = 3.14159... 是**永远不会变**的常数。程序中也有这类值，我们把它定义成"常量"防止被意外修改。

```c
// 方法1：#define（预处理常量，推荐用于固定值）
#define PI 3.14159       // 注意：define后面没有分号！没有等号！
#define MAX_STUDENTS 50  // 常量名通常全大写

// 方法2：const（只读变量，更安全，编译器会检查类型）
const int DAYS_IN_WEEK = 7;   // const 声明的变量不可修改
```

#### 3. 整数除法陷阱（必须警惕！）

```c
int a = 5;
int b = 2;
printf("%d\n", a / b);   // 输出 2，不是 2.5 ！！！

// 原因：两个整数相除，结果也是整数，小数部分直接扔掉（截断）
// 解决方法：把其中一个转成浮点数
printf("%f\n", 5.0 / 2);   // 输出 2.500000 ✅
printf("%f\n", (float)5 / 2); // 输出 2.500000 ✅ 强制类型转换
```

### 💻 上机敲代码

```c
/*
 * 文件名：day3_types.c
 * 功能：变量命名、常量、类型转换综合练习
 */

#include <stdio.h>

#define PI 3.14159          // 定义常量：圆周率（全大写命名）
#define BIRTH_YEAR 2008     // 定义常量：出生年份

int main()
{
    // ===== 一、变量的命名与使用 =====
    int studentAge = 18;           // 驼峰命名：学生年龄
    float examScore = 92.5;        // 考试成绩
    char bloodType = 'O';          // 血型

    printf("学生年龄：%d 岁\n", studentAge);
    printf("考试成绩：%.1f 分\n", examScore);
    printf("血型：%c 型\n", bloodType);

    // ===== 二、常量的使用 =====
    int currentYear = 2026;
    int age = currentYear - BIRTH_YEAR;   // 用常量计算年龄
    printf("出生于%d年，今年%d岁\n", BIRTH_YEAR, age);

    float radius = 5.0;                   // 圆的半径
    float area = PI * radius * radius;    // 用常量PI计算圆面积
    printf("半径为%.1f的圆，面积 = %.2f\n", radius, area);

    // const常量（只读变量）
    const int HOURS_PER_DAY = 24;
    // HOURS_PER_DAY = 25;  // ❌ 这行会报错！const变量不可修改
    printf("一天有%d小时\n", HOURS_PER_DAY);

    // ===== 三、整数除法 vs 浮点除法 =====
    printf("\n--- 整数除法陷阱演示 ---\n");
    printf("5 / 2 = %d        ← 整数除法，小数部分被截断！\n", 5 / 2);
    printf("5.0 / 2 = %.1f    ← 浮点除法，结果正确\n", 5.0 / 2);
    printf("5 / 2.0 = %.1f    ← 浮点除法，结果正确\n", 5 / 2.0);
    printf("(float)5 / 2 = %.1f ← 强制类型转换\n", (float)5 / 2);

    // ===== 四、强制类型转换 =====
    int total = 350;
    int count = 40;
    // 想要精确的平均值，需要类型转换
    float correctAvg = (float)total / count;   // 先把total转成float再除
    int wrongAvg = total / count;               // 整数除整数，得到整数
    printf("\n正确平均值：%.2f\n", correctAvg);  // 8.75 ✅
    printf("错误平均值：%d\n", wrongAvg);        // 8 ❌

    return 0;
}
```

---

### 📋 今日核心知识点总结

1. **变量命名**：字母/下划线开头，只能包含字母、数字、下划线，不能和关键字重名
2. **常量两种方式**：`#define PI 3.14`（无分号无等号）和 `const float PI = 3.14;`（有分号有等号）
3. **整数÷整数=整数**，小数部分被截断（不是四舍五入！）
4. **强制类型转换**：`(float)整数` 把整数临时变成浮点数
5. **const变量**声明后不能修改，试图修改会编译报错

## Day 4：输入输出——让你的程序和用户对话

### 🎯 今日学习目标
学完后你能：
- 使用 `scanf()` 接收用户输入
- 理解 `&` 取地址符号的作用（为指针打基础！）
- 写出可以和用户交互的简单程序

---

### 📖 通俗化知识点讲解

#### 1. scanf() 是什么？

> **生活类比**：`printf` 是你对别人说话（输出），`scanf` 是别人对你说话（输入）。
>
> 想象你在填一张表：
> - `printf("请输入你的名字：")` —— 你在表上印了这个问题
> - `scanf(...)` —— 对方拿起笔，在空格里写下答案
> - `&` 符号 —— 告诉对方"答案写在这个格子里"（格子的位置）

```c
int age;
printf("请输入你的年龄：");   // 先提示用户
scanf("%d", &age);             // 等用户输入，存到age这个变量里
                               // %d 表示我要读一个整数
                               // &age 表示"把输入的值存到age所在的内存位置"
```

#### 2. & 符号是什么？

> **核心理解**：`&age` 的意思是"变量age在内存中的地址"。
> 就像快递员需要你家的地址才能把包裹送到，`scanf` 需要变量的地址才能把输入的值放进去。
>
> 这是你第一次接触"地址"的概念！记住：**scanf 需要 &，printf 不需要 &**。

```c
int num = 10;
printf("%d\n", num);   // printf 只需要知道值是什么（10）
scanf("%d", &num);     // scanf 需要知道值放在哪里（num的地址）
```

#### 3. scanf 的占位符

| scanf占位符 | 读取类型 | 示例 |
|-------------|----------|------|
| `%d` | 整数 int | `scanf("%d", &age);` |
| `%f` | 浮点数 float | `scanf("%f", &score);` |
| `%lf` | 双精度 double | `scanf("%lf", &pi);` ← 注意是%lf不是%f！ |
| `%c` | 字符 char | `scanf(" %c", &grade);` ← 前面有个空格！ |

> ⚠️ **容易踩坑**：
> 1. `double` 用 `%lf`（long float），不是 `%f`

### 📖 通俗化知识点讲解

#### 1. 算术运算符

| 运算符 | 含义 | 例子 | 结果 |
|--------|------|------|------|
| `+` | 加法 | `5 + 3` | `8` |
| `-` | 减法 | `5 - 3` | `2` |
| `*` | 乘法 | `5 * 3` | `15` |
| `/` | 除法 | `5 / 2` | `2`（整数除整数=整数！） |
| `%` | 取余（模） | `5 % 2` | `1`（5除以2的余数） |

#### 2. 取余运算符 % 有什么用？

> **生活类比**：你分糖果，10颗糖分给3个人，每人3颗，剩下1颗。`10 % 3 = 1` 就是剩下的那颗。

**常见应用**：
- **判断奇偶数**：`num % 2 == 0` → 偶数，`num % 2 == 1` → 奇数
- **循环往复**：星期几的轮换、钟表的时针
- **取一个数的个位**：`123 % 10 = 3`

#### 3. 自增 ++ 和自减 --（C语言特色！）

> **生活类比**：计数器。
> - `count++` = "count的值涨1"（和 `count = count + 1` 效果一样）
> - `count--` = "count的值减1"

```c
int a = 5;
a++;      // 等价于 a = a + 1;  现在 a 变成 6
a--;      // 等价于 a = a - 1;  现在 a 变回 5
```

#### 4. 前置 ++ 和后置 ++ 的区别（重要！）

```c
int a = 5;
int b;

b = a++;   // 后置++：先把a的值赋给b，然后a再加1
           // 结果：b = 5, a = 6

b = ++a;   // 前置++：a先加1，再把新值赋给b
           // 结果：b = 7, a = 7（因为上一步a已经是6了）
```

> **记忆口诀**：
> - `a++` → "先用后加"（后置，after）
> - `++a` → "先加后用"（前置，before）

### 📖 通俗化知识点讲解

#### 1. 关系运算符 —— "比大小"

> **生活类比**：两个同学比身高。
> - `小明身高 > 小红身高` → 判断真假
> - 结果只有两种可能：**真（是）** 或 **假（否）**

| 运算符 | 含义 | 例子 | 结果 |
|--------|------|------|------|
| `>` | 大于 | `5 > 3` | 真（1） |
| `<` | 小于 | `5 < 3` | 假（0） |
| `>=` | 大于等于 | `5 >= 5` | 真（1） |
| `<=` | 小于等于 | `4 <= 3` | 假（0） |
| `==` | 等于 | `5 == 5` | 真（1） |
| `!=` | 不等于 | `5 != 3` | 真（1） |

> ⚠️ **致命陷阱**：`=` 是赋值，`==` 是比较！
> ```c
> int a = 5;       // = 赋值：把5放进a
> if (a == 5)      // == 比较：a等于5吗？
> if (a = 5)       // ❌ 这是赋值！永远为真！初学者最常见的Bug！
> ```

#### 2. 逻辑运算符 —— "而且/或者/不是"

> **生活类比**：考驾照的条件。
> - **科目一通过 && 科目二通过** → 才能拿驾照（而且：两门都过才行）
> - **英语过四级 || 计算机过二级** → 可以毕业（或者：满足一个就行）
> - **!挂科** → 表示没有挂科（不是/取反）

| 运算符 | 含义 | 例子 | 口诀 |
|--------|------|------|------|
| `&&` | 逻辑与（而且） | `a>60 && a<100` | 两边都为真，整体才为真 |
| `||` | 逻辑或（或者） | `a<0 || a>100` | 两边有一个为真，整体就为真 |
| `!` | 逻辑非（不是） | `!(a>100)` | 真变假，假变真 |

#### 3. C语言中的"真"与"假"

```c
// C语言没有真正的布尔类型（bool），用数字表示真假：
// 0 → 假（false）
// 非0（任何非零的数）→ 真（true），通常用1表示

if (1)  { printf("这行会执行\n"); }   // 1 = 真
if (0)  { printf("这行不会执行\n"); } // 0 = 假
if (100){ printf("这行会执行\n"); }   // 100 = 非零 = 真
if (-5) { printf("这行也会执行\n"); } // -5 = 非零 = 真
```

```c
/*
 * 文件名：relational_logical.c
 * 功能：关系运算符和逻辑运算符练习
 */

#include <stdio.h>

int main()
{
    // ===== 一、关系运算符 =====
    printf("===== 关系运算符 =====\n");
    printf("5 > 3  的结果：%d\n", 5 > 3);    // 真 → 1
    printf("5 < 3  的结果：%d\n", 5 < 3);    // 假 → 0
    printf("5 >= 5 的结果：%d\n", 5 >= 5);   // 真 → 1
    printf("5 <= 3 的结果：%d\n", 5 <= 3);   // 假 → 0
    printf("5 == 5 的结果：%d\n", 5 == 5);   // 真 → 1
    printf("5 != 3 的结果：%d\n", 5 != 3);   // 真 → 1

    // ===== 二、逻辑运算符 =====
    printf("\n===== 逻辑运算符 =====\n");

    // && (与) — 两边都真才为真
    printf("(5>3) && (2<4) 的结果：%d\n", (5>3) && (2<4));   // 1（都真）
    printf("(5>3) && (2>4) 的结果：%d\n", (5>3) && (2>4));   // 0（一真一假）

    // || (或) — 有一个真就为真
    printf("(5>3) || (2>4) 的结果：%d\n", (5>3) || (2>4));   // 1（有一个真）
    printf("(5<3) || (2>4) 的结果：%d\n", (5<3) || (2>4));   // 0（都假）

    // ! (非) — 取反
    printf("!(5 > 3) 的结果：%d\n", !(5 > 3));               // 0（真的反面=假）
    printf("!(5 < 3) 的结果：%d\n", !(5 < 3));               // 1（假的反面=真）

    // ===== 三、短路求值（面试常考！） =====
    printf("\n===== 短路求值 =====\n");

    int a = 5, b = 10;

    // && 短路：左边为假时，右边不再计算
    if ((a > 10) && (b = 999)) {   // a>10 是假，所以 && 右边不执行了
        printf("这个不会打印\n");
    }
    printf("短路后 b = %d（b还是10，因为右边没执行）\n", b);

    // || 短路：左边为真时，右边不再计算
    if ((a == 5) || (b = 999)) {   // a==5 是真，所以 || 右边不执行了
        printf("这个会打印\n");
    }
    printf("短路后 b = %d（b还是10，因为右边没执行）\n", b);

    // ===== 四、综合应用：判断成绩是否合法 =====
    printf("\n===== 成绩合法性判断 =====\n");
    int score = 85;
    int isValid = (score >= 0) && (score <= 100);  // 0~100之间
    printf("成绩 %d 是否合法？%d（1=合法，0=不合法）\n", score, isValid);

    score = 150;
    isValid = (score >= 0) && (score <= 100);
    printf("成绩 %d 是否合法？%d（1=合法，0=不合法）\n", score, isValid);

    return 0;
}
```

### 📖 通俗化知识点讲解

#### 1. if 语句——程序的分岔路

> **生活类比**：你出门前看天气预报。
> - **如果（if）** 下雨 → 带伞
> - **否则（else）** → 不带伞
>
> 程序也一样，需要根据不同条件走不同的"路"。

```c
// 结构1：单分支（只有if）
if (条件) {
    // 条件为真时执行
}

// 结构2：双分支（if-else）
if (条件) {
    // 条件为真时执行
} else {
    // 条件为假时执行
}

// 结构3：多分支（if-else if-else）
if (条件1) {
    // 条件1为真
} else if (条件2) {
    // 条件2为真
} else if (条件3) {
    // 条件3为真
} else {
    // 以上条件都不满足
}
```

#### 2. 代码块和花括号

```c
if (score >= 60)
    printf("及格了\n");       // 只有一行时可以省略花括号
    printf("恭喜你！\n");     // ⚠️ 但这行不属于if！无论是否及格都会执行！

// 正确做法：有多行时一定加花括号！
if (score >= 60) {
    printf("及格了\n");
    printf("恭喜你！\n");     // 这两行都属于if的"管辖范围"
}
```

> **建议**：即使只有一行，也建议加花括号。保持习惯一致性，减少Bug。

## Day 9：条件分支（下）—— switch 语句与嵌套if

### 🎯 今日学习目标
学完后你能：
- 掌握 switch-case 多分支选择结构
- 理解 break 在 switch 中的作用
- 知道什么场景用if，什么场景用switch

---

### 📖 通俗化知识点讲解

#### 1. switch 语句——多选一

> **生活类比**：食堂的套餐选择。
> - 选 1 → 红烧肉套餐
> - 选 2 → 糖醋排骨套餐
> - 选 3 → 番茄鸡蛋套餐
> - 选其他的 → 没有这个套餐
>
> switch 就像一个"多路开关"，根据一个值跳到对应的分支。

```c
switch (表达式) {         // 表达式只能是整数或字符（不能是浮点数！）
    case 值1:
        // 匹配值1时执行
        break;            // 跳出switch，不要忘记！
    case 值2:
        // 匹配值2时执行
        break;
    default:              // 所有case都不匹配时的"默认选项"
        // 默认执行
        break;
}
```

#### 2. break 的重要性——"瀑布效应"

```c
int day = 3;
switch (day) {
    case 1: printf("星期一\n");
    case 2: printf("星期二\n");
    case 3: printf("星期三\n");  // ← 从这里开始
    case 4: printf("星期四\n");  // 没有break，继续往下掉！
    case 5: printf("星期五\n");  // 所有后续case都会执行！
}
// 输出：星期三 星期四 星期五（全打印了！这不是你想要的！）
```

> ⚠️ **忘写break** 会导致"穿透"，继续执行下一个case的代码。有时候故意不写break来实现特殊逻辑，但99%的情况你都需要break。

#### 3. if vs switch —— 什么时候用哪个？

| 场景 | 用什么 | 原因 |
|------|--------|------|
| 判断范围（0-60/60-80/80-100） | if-else if | switch只能判断确定的值 |
| 判断确定的值（菜单选项1/2/3） | switch | 代码更清晰 |
| 复杂条件（&&、||） | if | switch不支持逻辑运算 |
| 浮点数判断 | if | switch不支持float/double |

### 💻 上机敲代码

```c
/*
 * 文件名：switch_demo.c
 * 功能：switch语句综合演示——简易菜单系统
 */

#include <stdio.h>

int main()
{
    int choice;          // 用户选择的菜单编号
    float balance = 1000.0;  // 账户余额
    float amount;        // 操作金额

    // 显示菜单
    printf("╔══════════════════╗\n");
    printf("║   简易银行系统   ║\n");
    printf("╠══════════════════╣\n");
    printf("║ 1. 查询余额      ║\n");
    printf("║ 2. 存款          ║\n");
    printf("║ 3. 取款          ║\n");
    printf("║ 4. 退出          ║\n");
    printf("╚══════════════════╝\n");
    printf("请选择操作（1-4）：");
    scanf("%d", &choice);

    // switch 处理用户选择
    switch (choice) {
        case 1:   // 查询余额
            printf("\n当前余额：%.2f 元\n", balance);
            break;

        case 2:   // 存款
            printf("\n请输入存款金额：");
            scanf("%f", &amount);
            if (amount > 0) {
                balance += amount;    // balance = balance + amount
                printf("存款成功！当前余额：%.2f 元\n", balance);
            } else {
                printf("❌ 金额必须大于0！\n");
            }
            break;

        case 3:   // 取款
            printf("\n请输入取款金额：");
            scanf("%f", &amount);
            if (amount > 0 && amount <= balance) {
                balance -= amount;    // balance = balance - amount
                printf("取款成功！当前余额：%.2f 元\n", balance);
            } else if (amount > balance) {
                printf("❌ 余额不足！当前余额：%.2f 元\n", balance);
            } else {
                printf("❌ 金额必须大于0！\n");
            }
            break;

        case 4:   // 退出
            printf("\n感谢使用，再见！\n");
            break;

        default:  // 输入了1-4以外的数字
            printf("\n❌ 无效选项，请输入1-4之间的数字！\n");
            break;
    }

    return 0;
}
```

---

### 📋 今日核心知识点总结

1. `switch(整型表达式)` 根据值跳到对应 `case`
2. 每个 case 末尾必须写 `break`，否则会"穿透"到下一个case
3. `default` 是可选的，处理所有不匹配的情况
4. switch 只能用于整数/字符，不能用于浮点数和范围判断
5. if 更灵活（支持范围和复杂逻辑），switch 更清晰（多选一的确定值）

## Day 11：循环结构（上）—— for 循环

### 🎯 今日学习目标

---

### 📖 通俗化知识点讲解

#### 1. 为什么需要循环？

> **生活类比**：体育课上老师让你绕操场跑10圈。
> - 如果"手动"写：跑第1圈、跑第2圈、跑第3圈...写到第10圈
> - 用"循环"写：`for (圈数=1; 圈数<=10; 圈数++) { 跑一圈; }`
>
> 循环就是**让一段代码重复执行多次**。

#### 2. for 循环的三要素

```c
for (初始化;  条件判断;  每次循环后执行) {
    // 循环体：重复执行的代码
}

//     ↓         ↓            ↓
for (int i = 1; i <= 10; i++) {
    printf("第%d次跑步\n", i);
}
```

> **记忆口诀**：
> 1. **初始化**（int i=1）：从哪开始？
> 2. **条件判断**（i<=10）：到哪结束？条件为假时停止
> 3. **更新**（i++）：每次结束后怎么变？

**执行顺序**：
```
初始化 → 判断条件 → （真）执行循环体 → 更新 → 判断条件 → ...
                  → （假）退出循环
```

---

### 💻 上机敲代码

```c
/*
 * 文件名：for_loop_demo.c
 * 功能：for循环的各种用法演示
 */

#include <stdio.h>

int main()
{
    // ===== 一、基本for循环：打印1到10 =====
    printf("===== 打印1到10 =====\n");
    for (int i = 1; i <= 10; i++) {
        printf("%d ", i);   // %d后面的空格让数字之间有间隔
    }
    printf("\n");   // 循环结束后换行

    // ===== 二、倒着数：打印10到1 =====
    printf("\n===== 打印10到1 =====\n");
    for (int i = 10; i >= 1; i--) {
        printf("%d ", i);
    }
    printf("\n");

    // ===== 三、步长不为1：打印1到10之间的奇数 =====
    printf("\n===== 1到10之间的奇数 =====\n");
    for (int i = 1; i <= 10; i += 2) {   // 每次跳2
        printf("%d ", i);
    }
    printf("\n");

    // ===== 四、累加求和：1+2+3+...+100 =====
    int sum = 0;   // 累加器，初始为0
    for (int i = 1; i <= 100; i++) {
        sum = sum + i;   // 每次把i加到sum里
    }
    printf("\n1到100的和 = %d（高斯公式验证：5050）\n", sum);

    // ===== 五、乘法口诀表（九九乘法表） =====
    printf("\n===== 九九乘法表 =====\n");
    for (int i = 1; i <= 9; i++) {         // 外层循环：行
        for (int j = 1; j <= i; j++) {     // 内层循环：列
            printf("%d×%d=%-2d  ", j, i, i * j);
            //             %-2d 表示左对齐占2位宽度，让表格整齐
        }
        printf("\n");   // 每行结束换行
    }

    return 0;
}
```

---

### 📋 今日核心知识点总结

1. for 循环三要素：**初始化、条件、更新**
2. 执行顺序：初始化(1次) → 判断 → 循环体 → 更新 → 判断...
3. `i++` 可以换成 `i+=2`（步长2）、`i+=5`（步长5）
4. for 可以嵌套（循环里面放循环）形成**嵌套循环**
5. 常见模式：累加求和、打印乘法表、遍历数列

## Day 12：循环结构（中）—— while 循环与 do-while 循环

### 🎯 今日学习目标
学完后你能：
- 掌握 while 循环的用法
- 理解 do-while 循环的特点（至少执行一次）
- 区分 for / while / do-while 的使用场景

---

### 📖 通俗化知识点讲解

#### 1. while 循环——"只要...就一直..."

> **生活类比**：吃饭。
> - **当（while）**碗里还有饭 → 继续吃
> - 碗空了 → 停止
>
> while 循环先判断条件，条件为真才进入循环。可能一次都不执行！

```c
while (条件) {
    // 条件为真时重复执行
}
```

#### 2. do-while 循环——"先做了再说"

> **生活类比**：游乐场的过山车。
> - 先坐上去玩一次（do）
> - 然后问"还要再玩吗？"（while）
>
> do-while **至少执行一次**，这是和while的最大区别！

```c
do {
    // 先执行一次
} while (条件);   // ← 注意这里有分号！
```

#### 3. for vs while vs do-while

| 循环类型 | 何时用 | 特点 |
|----------|--------|------|
| `for` | 知道循环次数 | 结构紧凑，三要素在一行 |
| `while` | 不知道循环次数，靠条件判断 | 可能一次都不执行 |
| `do-while` | 至少执行一次 | 先执行再判断 |

---

### 💻 上机敲代码

```c
/*
 * 文件名：while_loop_demo.c
 * 功能：while和do-while循环演示
 */

#include <stdio.h>

int main()
{
    // ===== 一、while 循环：打印1到10 =====
    printf("===== while循环：1到10 =====\n");
    int i = 1;               // 初始化
    while (i <= 10) {        // 条件判断
        printf("%d ", i);
        i++;                 // 更新（写在循环体里面，容易忘！）
    }
    printf("\n");

    // ===== 二、while 经典应用：数字反转 =====
    printf("\n===== 数字反转 =====\n");
    int num = 12345;
    int reversed = 0;
    int temp = num;          // 保存原始值

    while (temp > 0) {
        reversed = reversed * 10 + temp % 10;  // 取个位，接到结果后面
        temp = temp / 10;                      // 去掉个位
    }
    printf("%d 反转后是 %d\n", num, reversed);

    // ===== 三、do-while：必须输入合法值 =====
    printf("\n===== do-while：输入验证 =====\n");
    int score;
    do {
        printf("请输入成绩（0-100）：");
        scanf("%d", &score);
        if (score < 0 || score > 100) {
            printf("❌ 成绩不合法，请重新输入！\n");
        }
    } while (score < 0 || score > 100);  // 不合法就继续问
    printf("✅ 成绩 %d 输入成功！\n", score);

    // ===== 四、while 经典应用：猜数字游戏框架 =====
    printf("\n===== 猜数字游戏 =====\n");
    int secret = 42;    // 要猜的数字（后面学随机数可以改）
    int guess;
    int attempts = 0;   // 猜测次数

    printf("我想了一个1-100之间的数字，来猜猜看！\n");

    while (1) {   // 1 永远为真 = 无限循环
        printf("你的猜测：");
        scanf("%d", &guess);
        attempts++;   // 猜测次数+1

        if (guess > secret) {
            printf("太大了！往下猜。\n");
        } else if (guess < secret) {
            printf("太小了！往上猜。\n");
        } else {
            printf("🎉 猜对了！你用了 %d 次。\n", attempts);
            break;   // break可以跳出循环（不只是switch！）
        }
    }

    return 0;
}
```

---

### 📋 今日核心知识点总结

1. `while(条件)` 先判断再执行，可能一次都不执行
2. `do { } while(条件);` 先执行再判断，**至少执行一次**，注意末尾分号
3. `break` 可以跳出循环（也可跳出switch）
4. 无限循环：`while(1)` 或 `for(;;)`，需要break跳出
5. while 循环的更新语句写在循环体里，容易忘记——要特别注意！

## Day 13：循环结构（下）—— break与continue、循环嵌套

### 🎯 今日学习目标
学完后你能：
- 掌握 break 和 continue 的区别
- 理解循环嵌套的执行流程
- 综合运用三种循环解决实际问题

---

### 📖 通俗化知识点讲解

#### 1. break vs continue

> **生活类比**：你在图书馆看书。
> - **break**：管理员说"闭馆了！"→ 你直接离开图书馆（**结束整个循环**）
> - **continue**：有人打电话来 → 你出去接电话，然后**回来继续**看书（**跳过本次循环的剩余部分**）

```c
// break 演示
for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        break;        // i=5时退出整个循环
    }
    printf("%d ", i); // 输出：1 2 3 4
}

// continue 演示
for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        continue;     // i=5时跳过本次循环剩余部分
    }
    printf("%d ", i); // 输出：1 2 3 4 6 7 8 9 10（跳过了5）
}
```

#### 2. 嵌套循环的执行顺序

```c
for (int i = 1; i <= 3; i++) {       // 外层
    for (int j = 1; j <= 3; j++) {   // 内层
        printf("(%d, %d) ", i, j);
    }
    printf("\n");
}
// 输出：
// (1,1) (1,2) (1,3)   ← 外层i=1，内层j=1,2,3全部跑完
// (2,1) (2,2) (2,3)   ← 外层i=2，内层j=1,2,3全部跑完
// (3,1) (3,2) (3,3)   ← 外层i=3，内层j=1,2,3全部跑完
```

> **规律**：外层循环一次，内层循环跑一轮。

---

### 💻 上机敲代码

```c
/*
 * 文件名：loop_advanced.c
 * 功能：break/continue/嵌套循环综合练习
 */

#include <stdio.h>

int main()
{
    // ===== 一、break 和 continue 的区别 =====
    printf("===== break演示 =====\n");
    for (int i = 1; i <= 10; i++) {
        if (i == 6) {
            break;   // 到6就停了
        }
        printf("%d ", i);
    }
    printf("← break后循环结束\n\n");

    printf("===== continue演示 =====\n");
    for (int i = 1; i <= 10; i++) {
        if (i == 6) {
            continue;  // 跳过6，继续后面的
        }
        printf("%d ", i);
    }
    printf("← continue跳过6但循环继续\n\n");

    // ===== 二、素数判断 =====
    printf("===== 2到100之间的素数 =====\n");
    int count = 0;
    for (int num = 2; num <= 100; num++) {
        int isPrime = 1;   // 先假设num是素数
        for (int divisor = 2; divisor * divisor <= num; divisor++) {
            if (num % divisor == 0) {   // 找到了因子
                isPrime = 0;            // 不是素数
                break;                  // 不用继续找了，跳出内层循环
            }
        }
        if (isPrime == 1) {
            printf("%d ", num);
            count++;
            if (count % 10 == 0) {      // 每10个换一行
                printf("\n");
            }
        }
    }
    printf("\n共 %d 个素数\n", count);

    // ===== 三、打印图案：直角三角形 =====
    printf("\n===== 直角三角形 =====\n");
    for (int row = 1; row <= 5; row++) {
        for (int col = 1; col <= row; col++) {
            printf("* ");
        }
        printf("\n");
    }

    // ===== 四、打印图案：等腰三角形 =====
    printf("\n===== 等腰三角形 =====\n");
    int height = 5;
    for (int row = 1; row <= height; row++) {
        // 打印空格（左边的空白）
        for (int space = 1; space <= height - row; space++) {
            printf("  ");
        }
        // 打印星号
        for (int star = 1; star <= 2 * row - 1; star++) {
            printf("* ");
        }
        printf("\n");
    }

    return 0;
}
```

---

### 📋 今日核心知识点总结

1. `break`：**彻底退出**当前循环（不是退出if！）
2. `continue`：**跳过本次**循环的剩余部分，进入下一次迭代
3. 嵌套循环：外层一次，内层一轮；总执行次数 = 外层次数 × 内层次数
4. 使用break可以提前退出循环，避免不必要的计算（如素数判断找到了因子就停止）

### 💻 上机敲代码

```c
/*
 * 文件名：guess_number_game.c
 * 功能：完整的猜数字游戏（1-100）
 * 覆盖知识点：变量、输入输出、循环、if判断、随机数、break/continue
 */

#include <stdio.h>
#include <stdlib.h>   // rand() 和 srand() 需要
#include <time.h>     // time() 需要，用于生成真随机数

int main()
{
    int secret;       // 秘密数字
    int guess;        // 玩家猜测
    int attempts;     // 猜测次数
    int low = 1;      // 提示范围下界
    int high = 100;   // 提示范围上界
    char playAgain;   // 是否再玩一局

    // 用当前时间作为随机数种子（确保每次运行数字不同）
    srand((unsigned int)time(NULL));

    printf("╔══════════════════════════╗\n");
    printf("║      🎯 猜数字游戏       ║\n");
    printf("║   我想了一个1-100的数字  ║\n");
    printf("║     你来猜猜看！         ║\n");
    printf("╚══════════════════════════╝\n");

    do {
        // 新一局：生成随机数，重置计数器
        secret = rand() % 100 + 1;   // rand()%100 生成0-99，+1变成1-100
        attempts = 0;
        low = 1;
        high = 100;

        printf("\n--- 新游戏开始！我已经想好了数字。---\n");

        // 猜数循环
        while (1) {
            printf("\n范围 [%d, %d]，请输入你的猜测：", low, high);
            scanf("%d", &guess);
            attempts++;

            // 输入合法性检查
            if (guess < 1 || guess > 100) {
                printf("❌ 请输入1-100之间的数字！\n");
                attempts--;  // 无效输入不计入次数
                continue;    // 跳过本次循环
            }

            // 判断大小
            if (guess > secret) {
                printf("📉 太大了！\n");
                if (guess < high) {
                    high = guess - 1;  // 缩小范围上界
                }
            } else if (guess < secret) {
                printf("📈 太小了！\n");
                if (guess > low) {
                    low = guess + 1;   // 扩大范围下界
                }
            } else {
                // 猜中了！
                printf("\n🎉 恭喜你猜对了！数字就是 %d！\n", secret);
                printf("📊 你一共猜了 %d 次。\n", attempts);

                // 评价
                if (attempts <= 5) {
                    printf("🏆 评价：天才级别的直觉！\n");
                } else if (attempts <= 8) {
                    printf("👍 评价：很不错，运气和推理兼备！\n");
                } else if (attempts <= 12) {
                    printf("🙂 评价：正常发挥，还有优化空间。\n");
                } else {
                    printf("💪 评价：多练练二分查找策略会更快哦！\n");
                }
                break;   // 退出猜数循环
            }
        }

        // 是否再来一局
        printf("\n还要再玩一局吗？（y/n）：");
        scanf(" %c", &playAgain);   // 注意%c前的空格

    } while (playAgain == 'y' || playAgain == 'Y');

    printf("\n感谢游玩，再见！👋\n");
    return 0;
}
```

---

### 📋 今日核心知识点总结

1. `rand()` 生成伪随机数（0到RAND_MAX），`rand() % 100` 得到0-99
2. `srand(time(NULL))` 用当前时间做种子，让每次运行随机数都不同
3. `continue` 跳过无效输入，让循环重新开始
4. `break` 猜对后退出死循环
5. 综合运用了前14天学到的几乎全部知识点！
