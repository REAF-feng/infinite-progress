```
│           🐛 报错记录卡                   │
├──────────────────────────────────────────┤

│ 报错信息（原文粘贴）：                     │
│ _____________________________________     │
│ _____________________________________     │
│                                          │
│ 原因分析：                                │
│ _____________________________________     │
│                                          │
│ 解决方法：                                │
│ _____________________________________     │
│                                          │
│ 涉及知识点：                              │
│ _____________________________________     │
│                                          │
│ 同类问题预防提示：                         │
│ _____________________________________     │
│                                          │
└──────────────────────────────────────────┘
```

### 报错记录示例

```
┌──────────────────────────────────────────┐
│           🐛 报错记录卡                   │
├──────────────────────────────────────────┤
│ 编号：001                                 │
│ 日期：7月15日                             │
│ 报错信息：                                │
│ error: expected ';' before 'return'       │
│                                          │
│ 原因分析：                                │
│ printf语句末尾忘了写分号                   │
│                                          │
│ 解决方法：                                │
│ 在printf行末加上;                         │
│                                          │
│ 涉及知识点：                              │
│ C语言语句必须以分号结尾                   │
│                                          │
│ 同类问题预防提示：                         │
│ 每写完一行代码，先检查末尾有没有分号再继续 │
└──────────────────────────────────────────┘
```
