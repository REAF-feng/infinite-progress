> 📌 C语言的灵魂——指针。这篇图解笔记帮你建立清晰的内存模型。配合 Day 29-37 讲义使用。

## 一、指针是什么——一张图看懂

```
                   内存（可以理解为一个大数组）
                   │
    地址: 0x100    0x104    0x108    0x10C    0x110
          ↓         ↓         ↓         ↓         ↓
    ┌─────────┬─────────┬─────────┬─────────┬─────────┐
    │   10    │         │  0x100  │         │         │
    └─────────┴─────────┴─────────┴─────────┴─────────┘
        ↑                   ↑
      变量 a              变量 p
     (int a = 10)      (int *p = &a)
     值=10              值=0x100(a的地址)
     地址=0x100          地址=0x108

关键关系：
  a 的值 = 10            （直接存在a里）
  &a     = 0x100         （a的地址）
  p 的值 = 0x100         （p存的是a的地址）
  &p     = 0x108         （p自己的地址）
  *p     = 10            （解引用：去p存的地址那里取值）
```

## 二、`&` 和 `*` 的关系——互为逆运算

```
       &（取地址）
  变量 ──────────→ 地址
       ←──────────
       *（解引用）

  &a → a的地址
  *p → p指向的值

  *(&a) = a       （先去地址再解引用 = 回到原值）
  &(*p) = p        （先解引用再取地址 = 回到原指针）
```

**记忆口诀**：
- `&` = "这个变量的家在哪？"（给它地址）
- `*` = "这个地址的家里有什么？"（取它指向的值）

## 三、指针与数组——一张图理解 `arr[i] == *(arr+i)`

```
int arr[] = {10, 20, 30, 40, 50};

内存布局（假设 arr 从地址 0x200 开始，每个int占4字节）：

地址:  0x200  0x204  0x208  0x20C  0x210
       ┌──────┬──────┬──────┬──────┬──────┐
       │  10  │  20  │  30  │  40  │  50  │
       └──────┴──────┴──────┴──────┴──────┘
         ↑      ↑      ↑      ↑      ↑
       arr[0]  arr[1] arr[2] arr[3] arr[4]
       *(arr) *(arr+1) *(arr+2) *(arr+3) *(arr+4)

arr 的值 = 0x200（指向第一个元素）
arr + 1  = 0x204（跳过一个int，即4字节）
arr + 2  = 0x208（跳过两个int，即8字节）

注意：arr + 1 不是 0x201！
      编译器自动处理了 sizeof(int) 的乘法。
```

## 四、指针的算术运算

```
int arr[] = {10, 20, 30, 40, 50};
int *p = arr;        // p 指向 arr[0]，即地址 0x200

p        → 地址 0x200，*p = 10
p + 1    → 地址 0x204，*(p+1) = 20
p + 2    → 地址 0x208，*(p+2) = 30

p++ 之后：p 指向 0x204（p本身的值变了）
p-- 之后：p 指向 0x200（又回来了）

指针减法：
int *p1 = &arr[4];   // 指向 0x210
int *p2 = &arr[1];   // 指向 0x204
p1 - p2 = 3          // 两个指针之间差3个元素
// 注意：p1 - p2 = (0x210-0x204)/4 = 12/4 = 3
```

## 五、指针与函数——传值 vs 传址

```
【值传递】—— 函数收到的是"复印件"

main:                    swap函数内:
┌──────┐                ┌──────┐
│ x=10 │                │ a=10 │  ← 修改a不影响x
│ y=20 │                │ b=20 │  ← 修改b不影响y
└──────┘                └──────┘
   ↑ 复制值 → → → → → → → ↑


【传址调用】—— 函数收到的是"地址"

main:                    swap函数内:
┌──────┐                ┌──────────┐
│ x=10 │←───────────────│ a=&x     │  *a修改的就是x！
│ y=20 │←───────────────│ b=&y     │  *b修改的就是y！
└──────┘                └──────────┘

调用：swap(&x, &y)       定义：void swap(int *a, int *b)
```

## 六、二级指针——指向指针的指针

```
int value = 100;
int *p = &value;
int **pp = &p;

内存布局：

    pp                p               value
┌──────────┐    ┌──────────┐    ┌──────────┐
│ 0x300    │───→│ 0x200    │───→│   100    │
└──────────┘    └──────────┘    └──────────┘
 地址:0x400      地址:0x300      地址:0x200

关系：
  pp    = 0x300（p的地址）
  *pp   = 0x200（= p的值 = value的地址）
  **pp  = 100   （= value的值）

访问value的三种方式：
  value  直接访问
  *p     通过一级指针
  **pp   通过二级指针
```

## 七、指针数组 vs 数组指针

### 7.1 指针数组（Array of Pointers）

```
int a=10, b=20, c=30;
int *ptrArr[3] = {&a, &b, &c};

ptrArr:
┌──────────┬──────────┬──────────┐
│  &a      │  &b      │  &c      │   ← 3个指针
└────┬─────┴────┬─────┴────┬─────┘
     │          │          │
     ▼          ▼          ▼
   ┌───┐     ┌───┐     ┌───┐
   │10 │     │20 │     │30 │
   └───┘     └───┘     └───┘

ptrArr[i] 是一个指针
*ptrArr[i] 是指针指向的值
```

### 7.2 数组指针（Pointer to Array）

```
int arr[5] = {1, 2, 3, 4, 5};
int (*pArr)[5] = &arr;   // pArr指向"整个数组"

pArr 指向的是这个整体：
┌───┬───┬───┬───┬───┐
│ 1 │ 2 │ 3 │ 4 │ 5 │
└───┴───┴───┴───┴───┘

*pArr  是数组本身
(*pArr)[0] = arr[0] = 1
```

## 八、动态内存——栈 vs 堆

```
┌────────────────────────────────────┐
│           程序的虚拟地址空间        │
├────────────────────────────────────┤
│  高地址                            │
│  ┌──────────┐                      │
│  │   栈     │ ← 局部变量、函数调用  │
│  │  Stack   │   自动分配、自动释放  │
│  │   ↓      │   大小有限（~几MB）   │
│  │   ...    │                      │
│  │   ↑      │                      │
│  │   堆     │ ← malloc/free        │
│  │  Heap    │   手动分配、手动释放  │
│  └──────────┘   大小受物理内存限制  │
│  ┌──────────┐                      │
│  │ 全局数据  │ ← 全局变量、static   │
│  ├──────────┤                      │
│  │  代码段   │ ← 程序的机器指令     │
│  └──────────┘                      │
│  低地址                            │
└────────────────────────────────────┘
```

**malloc 和 free 的内存变化**：

```
int *p = malloc(3 * sizeof(int));   // 在堆上分配3个int

堆:
┌──────┬──────┬──────┐
│  ?   │  ?   │  ?   │   ← 未初始化的3个int（12字节）
└──────┴──────┴──────┘
  ↑
  p 指向这里

p[0] = 10; p[1] = 20; p[2] = 30;

堆:
┌──────┬──────┬──────┐
│  10  │  20  │  30  │
└──────┴──────┴──────┘
  ↑
  p

free(p);    // 归还给系统
p = NULL;   // 指针置空，防止误用

堆:                       栈上的p:
┌────────────────┐      ┌──────┐
│  (已归还系统)   │      │ NULL │
└────────────────┘      └──────┘
```

## 九、链表指针图解

```
链表在内存中（节点不再连续！）：

  head = 0x500
    │
    ▼
  ┌─────────────────┐
  │ data: 10        │  地址: 0x500
  │ next: 0x720 ────┼────────┐
  └─────────────────┘        │
                             ▼
              ┌─────────────────┐
              │ data: 20        │  地址: 0x720
              │ next: 0x880 ────┼────────┐
              └─────────────────┘        │
                                         ▼
                          ┌─────────────────┐
                          │ data: 30        │  地址: 0x880
                          │ next: NULL      │
                          └─────────────────┘

节点分散在堆的不同位置，靠 next 指针串联！
```

### 插入节点图解（头插法）

```
原链表：head → [10|●] → [20|●] → [30|NULL]

插入值为5的新节点：

Step 1: 创建新节点
        [5|?]

Step 2: 新节点的next指向原来的头
        [5|●]──→ [10|●] → ...

Step 3: head指向新节点
        head → [5|●] → [10|●] → [20|●] → [30|NULL]

代码：
  newNode->next = head;   // Step 2
  head = newNode;         // Step 3
```

### 删除节点图解

```
删除值为20的节点：

原链表：head → [10|●] → [20|●] → [30|NULL]
                  ↑        ↑
                prev     temp(要删除的)

Step 1: prev->next = temp->next  （跳过temp）
        [10|●] ──────────→ [30|NULL]
                  [20|●]  ← 这个节点被孤立了

Step 2: free(temp)  （释放被孤立的节点）

结果：head → [10|●] → [30|NULL]
```

## 十、常见指针错误图解

### 错误1：野指针
```
int *p;      // 声明但未初始化
*p = 10;     // ❌ p指向哪？不知道！访问随机地址！
```

### 错误2：悬挂指针
```
int *p = malloc(sizeof(int));
*p = 10;
free(p);     // 内存归还了
*p = 20;     // ❌ p还指向原来的地址，但那个地址已不属于你！
             //    就像拿着过期房卡去开已退房的酒店房间。
```

### 错误3：内存泄漏
```
void func() {
    int *p = malloc(100);   // 分配了100字节
    // 使用p...
    return;                 // ❌ 没有free(p)！100字节永远丢失了！
}
// 每次调用func泄露100字节，程序运行时间长了内存耗尽
```

### 错误4：返回局部变量地址
```
int* func() {
    int x = 10;       // x在栈上
    return &x;        // ❌ 返回后栈空间被回收，x不存在了！
}
// 调用者得到一个指向"已废弃内存"的指针
```
