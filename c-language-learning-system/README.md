## ⚠️ 使用前必读

1. **不要跳步**：本体系按依赖关系严格编排，Day N 依赖 Day N-1 的知识
2. **必须敲代码**：只看不敲 = 白学。每天至少手打50行代码
3. **善用附录**：遇到报错先去 [appendix-b](appendix-b-编译报错大全.md) 查，培养独立排错能力
4. **打卡不能断**：连续打卡是坚持的关键，允许偶尔休息但不要连续断2天以上
5. **提问的艺术**：遇到问题先自己调试10分钟 → 查附录 → 搜索引擎 → 最后再问人
